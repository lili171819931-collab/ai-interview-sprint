# AI 平台架构素养（产品能对话的程度）

> 目标不是成为架构师，而是能和架构师对齐，并做出平台产品判断。

## 你要能画的一张图

```
业务应用 → AI 网关（鉴权/限流/路由/审计）
         → Prompt & 工具注册
         → 模型层（多模型/多供应商）
         → RAG/Agent 运行时
         → 评测 & 观测 & 成本
         → 数据/权限/合规
```

## 平台价值怎么讲

1. **降重复**：避免每个业务自己接模型
2. **提质量**：统一评测、提示词、知识与工具规范
3. **控风险**：权限、审计、安全策略集中
4. **控成本**：缓存、路由便宜模型、预算
5. **加速创新**：让业务方更安全地试验

## 高频权衡（面试加分）

| 议题 | 选项 A | 选项 B | 你怎么判 |
|------|--------|--------|----------|
| 模型 | 统一强模型 | 按场景路由 | 看任务难度/成本/延迟 |
| 知识 | 中央知识库 | 业务自建库 | 看治理能力与权限 |
| Agent | 平台统一运行时 | 业务自建 | 看安全与复用 |
| 评测 | 平台强制闸门 | 业务自愿 | 关键链路必须强制 |
