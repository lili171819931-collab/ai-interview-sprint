# AI Interview Sprint（14 天极限冲刺）

> 状态：待业全日可学｜目标：2 周后极限面试｜主岗位：**AI 产品经理**｜辅能力：**AI 平台架构对话力**

## 一句话策略

不追求成为算法专家；用 14 天把自己打造成「能定义 AI 产品价值、能和工程对齐、能讲清平台取舍」的候选人。

## 岗位优先级（已替你拍板）

| 优先级 | 岗位 | 原因 |
|--------|------|------|
| P0 | AI 产品经理 / AI 业务产品 | 你有 PM 底子，2 周内转化率最高 |
| P1 | AI 应用产品（LLM App / Agent / 知识库） | 与当前市场岗位重合大，故事好讲 |
| P2 | AI 平台产品（MaaS / 评测 / 网关 / Prompt 平台） | 加分方向，掌握「能对话」即可 |
| 暂缓 | 算法工程师 / 深度平台架构师 | 2 周无法从 0 建立可信度 |

## 仓库怎么用

1. 每天按 [`01-curriculum/day-by-day.md`](01-curriculum/day-by-day.md) 执行
2. 学完一个主题，立刻写思维链到 `07-thinking-chain/`
3. 同步产出面试口述稿到 `06-interview/`
4. 每天至少 1 次 git commit（学习证据）

## 每日最低剂量（再忙也做）

- 上午：概念 + 案例拆解（2h）
- 下午：项目/题库实战（3h）
- 晚上：口述演练 + 思维链（1.5h）
- 总计约 **6.5h/天**；全日可学时冲到 **8–10h**

## 14 天后验收（通过才算准备好投递）

- [ ] 60 秒自我介绍流畅
- [ ] 3 个项目/经历故事可深挖 15 分钟
- [ ] 能讲清 RAG / Agent / Eval / 幻觉 / 成本 的产品含义
- [ ] 能画并讲解一版「AI 应用 or 平台」架构（产品视角）
- [ ] 模拟面总分 ≥ 75/100
- [ ] 投递材料：简历 1 版 + 作品说明 1 页 + 岗位清单
