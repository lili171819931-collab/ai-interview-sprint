# 14 天极限日历

节奏：每天 3 块 —— **学（输入）/ 做（产出）/ 讲（面试转化）**  
每天结束必须：`git commit` + 一条思维链 + 1 道题口述

---

## Week 1｜建立可信度（概念 → 框架 → 作品骨架）

### Day 1｜定位 + 材料启动
**学**：AI 岗位地图；AI PM vs 平台产品 vs 算法差异  
**做**：
- 填写 `00-north-star/target-roles.md`（今天投哪些岗位）
- 简历草稿 v0（先框架后润色）
**讲**：60 秒自我介绍 v0  
**验收**：自我介绍能说清「我是谁 / 我解决什么 / 我为什么适合 AI 产品」

### Day 2｜LLM 产品底盘
**学**：Token、上下文窗口、温度、系统提示、结构化输出、幻觉  
**做**：整理 1 页「LLM 产品词汇表」（自己的话）  
**讲**：解释「幻觉」给非技术老板听（2 分钟）  
**验收**：能回答「为什么不能把 LLM 当数据库」

### Day 3｜RAG 全链路（产品视角）
**学**：文档解析 → 切分 → 向量化 → 检索 → 重排 → 生成 → 引用  
**做**：画出 RAG 产品流程图 + 失败点清单  
**讲**：对比「裸 LLM」vs「RAG」的适用场景  
**验收**：能讲清 5 个检索失败原因与产品对策

### Day 4｜Agent 与工具调用
**学**：规划、工具、记忆、人机回环、权限、失控风险  
**做**：设计一个 Agent 功能（含权限与兜底）  
**讲**：什么时候不该做 Agent  
**验收**：有一张 Agent 决策树（做 / 不做 / 人审）

### Day 5｜评测、成本、上线闸门
**学**：离线评测、线上反馈、黄金集、延迟、成本、安全  
**做**：写一版「AI 功能上线检查清单」  
**讲**：如何定义 AI 功能的成功指标  
**验收**：能用业务指标 + 模型指标两套语言说话

### Day 6｜主作品 Day A（选题与 PRD）
**做**：完成 `05-projects/02-ai-weekly-insight/` 主项目 PRD v1（若已完成则精修口述）  
建议选题（已拍板）：
1. ~~企业知识库问答~~
2. **微迹 AI 周复盘（主做）**
3. ~~AI 评测平台（可作演进叙事）~~
**讲**：项目电梯稿 90 秒  
**验收**：PRD 含：用户、场景、指标、流程、边界、风险

### Day 7｜主作品 Day B + 周复盘
**做**：架构说明 + 方案权衡 + 里程碑；补齐故事 STAR  
**讲**：模拟深挖 15 分钟（对着题单自问自答）  
**验收**：
- 周复盘写入 `07-thinking-chain/weekly-reviews/week-1.md`
- 模拟面自我评分 ≥ 60

---

## Week 2｜平台对话力 + 面试肌肉（追问 → 模拟 → 投递）

### Day 8｜AI 平台架构素养
**学**：模型网关、路由、限流、Key 管理、Prompt 管理、观测  
**做**：画「AI 中台/平台」能力地图（产品视角）  
**讲**：平台型产品如何创造复利  
**验收**：能解释「为何业务方不该直接连裸模型 API」

### Day 9｜数据、安全、合规、组织协作
**学**：隐私、脱敏、审计、提示注入、版权、人审机制  
**做**：写「AI 功能风险清单」并映射到产品方案  
**讲**：和法务/安全如何对齐  
**验收**：追问「数据出域怎么办」不卡壳

### Day 10｜辅作品 / Demo 最小闭环
**做**：`05-projects/03-rag-validation-lab/` 最小说明 + 黄金集评测表（可紧贴周复盘）  
若不会写代码：用「产品原型 + 伪代码流程 + 评测表」也成立  
**讲**：把 demo 讲成「验证了哪个假设」  
**验收**：作品夹可发给面试官（README 清晰）

### Day 11｜高频题攻坚（上）
**做**：完成题库前 15 题口述稿（见 `06-interview/`）  
**讲**：每题录音或计时口述，超时重来  
**验收**：15 题中 ≥ 10 题可 60–90 秒答完

### Day 12｜高频题攻坚（下）+ 系统设计
**做**：后 15 题 + 1 道系统设计（AI 知识库 or AI 网关）  
**讲**：系统设计 20 分钟完整演练  
**验收**：结构稳定：需求→约束→方案→权衡→指标→演进

### Day 13｜全真模拟面（两轮）
**做**：
- 模拟面 1：AI PM 综合（60–90 分钟）
- 模拟面 2：平台产品/架构对话（45 分钟）
**记录**：`06-interview/mock-interviews/mock-01.md`  
**验收**：总分趋势向上；卡壳题进入错题本

### Day 14｜材料收口 + 投递开火
**做**：
- 简历终稿
- 作品 README 终稿
- 岗位清单 20+（AI PM / AI 应用产品 / AI 平台产品）
- 自我介绍终版 + 反问问题清单
**讲**：最终走查 30 分钟  
**验收**：达到 README 中的「14 天后验收」清单

## 降级策略（状态不好时）

若某天只能学 3 小时，只做这三件：
1. 1 个核心概念卡片
2. 1 道面试题口述
3. 1 条思维链 + git commit

绝不「啥都不提交地空过一天」。
