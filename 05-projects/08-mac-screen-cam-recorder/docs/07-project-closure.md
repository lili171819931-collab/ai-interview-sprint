# 项目收口与复盘

## 1. 目标回顾

完成 Mac 本地教学录屏从调研到可运行 App 的闭环，并沉淀完整项目文档供面试讲述。

## 2. 已达成

- 可运行 Electron App：合成录制、MP4 导出、操作条、PiP 手势、虚化、缩放。
- 文档：立项、调研、竞品、需求冻结、PRD、IA、旅程、设计、项目管理、研发、测试、发布、商业与面试包装。

## 3. 业务价值（面试叙事）

1. 把「工具选型」做成可演示的产品判断：本地隐私 vs 云分享。
2. 用工程细节服务体验承诺：真 MP4、真时长、真本机摄像头。
3. 用文档地图证明能带项目走完全流程，而不只会写页面。

## 4. 经验

- 成功：先冻结「预览=成片」与「格式诚实」，减少返工。
- 成功：权限与 Continuity 作为一等公民写进验收。
- 待提升：公证分发、系统声、自动化实机测试。

## 5. 下一步（若继续产品化）

1. 签名公证 + 简单官网
2. 系统声与多屏选择 UX
3. 模板化片头/分辨率预设（仍保持本地）
