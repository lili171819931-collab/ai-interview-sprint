# 需求冻结：Mac Screen Cam Recorder

> 冻结日期：2026-08-11 · 状态：MVP+教学增强 已实现并归档

## 1. 必须有（P0）

- [x] macOS 屏幕/窗口采集 + 权限引导
- [x] 电脑摄像头圆形/方形 PiP，可拖动，预览=成片
- [x] 麦克风开关与电平
- [x] 开始/暂停/停止；倒计时可选
- [x] 导出桌面 `Mac录屏` 下 H.264 MP4 + JSON sidecar
- [x] 悬浮操作条（录制中主窗可隐藏时出现）
- [x] 录制中摄像头悬浮小窗：拖动、单击切形、双击反转

## 2. 应该有（P1）

- [x] MediaPipe 背景虚化（失败降级）
- [x] 水平镜像、大小预设
- [x] 截图、捕获历史、托盘与全局快捷键
- [x] 指针/捏合缩放（教学看清网页）
- [x] 排除 Continuity 手机摄像头

## 3. 可以有（P2 / 未做）

- [ ] 系统声 loopback
- [ ] 多显示器精细映射 UI
- [ ] 自动章节标记 / AI 字幕
- [ ] 正式签名公证的 .dmg 分发

## 4. 明确不做

- 非 macOS 客户端
- 云存储与账号体系
- 美颜商场与直播连麦

## 5. 验收口径（摘要）

详见 `验收清单.md`。关键句：QuickTime 打开 MP4，可见屏幕画面 + 出镜小窗 + 可听人声；操作条时长与成片时长误差在体感 1s 内（不含倒计时）。
