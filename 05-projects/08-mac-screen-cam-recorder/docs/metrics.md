# 指标定义

## 北星（作品集阶段）

**首次成功出片率**：新环境安装后，30 分钟内产出可在 QuickTime 播放的 MP4 的比例。

## 支持指标

| 指标 | 定义 | 采集 |
|------|------|------|
| 成片可播率 | MP4 可被 QuickTime 打开 | 手工 / sidecar encode 字段 |
| 时长偏差 | \|操作条秒数 − 播放器秒数\| | 抽检 |
| 开录失败率 | preparing→idle 且无文件 | 错误文案归类 |
| Continuity 误开次数 | 打开手机摄像头次数 | 日志/访谈 |

- 下载量（未分发）
