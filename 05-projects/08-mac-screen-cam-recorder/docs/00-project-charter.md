# 项目立项书：Mac Screen Cam Recorder（教学录屏）

## 1. 项目背景

知识创作者、独立讲师、产品经理在 Mac 上录制「屏幕讲解 + 真人出镜」时，常见工具要么偏直播带货、要么偏云端协作，本地轻量、所见即所得、圆形出镜可控的路径并不好用。系统自带截屏快捷键无法同时完成圆窗出镜与麦克风合成；Cap / Loom 等偏分享与 AI，学习成本与隐私边界对「本机教学成片」过重。

## 2. 项目目标

- 交付可运行的 **macOS-only** Electron 录屏 App：屏幕 + 圆形/方形摄像头 PiP + 麦克风，实时 Canvas 合成。
- 成片默认导出 **H.264 MP4** 至桌面 `Mac录屏`，QuickTime 可播，避免「网页版 WebM」误触。
- 悬浮操作条与可拖动摄像头小窗支持录制中持续操作（切形 / 反转 / 启停）。
- 形成从市场调研 → 竞品 → PRD → 设计 → 研发 → 验收 → 复盘的**面试可讲完整闭环文档**。

## 3. 成功标准（Definition of Success）

| 维度 | 标准 |
|------|------|
| 功能 | 选屏 → 开摄像头/麦 → 预览所见即所得 → 录制 → 桌面 MP4 |
| 出镜 | 圆/方切换、拖动改成片位置、水平反转；录制中悬浮小窗可操作 |
| 隐私 | 无账号、无上传；悬浮监视窗 contentProtection 不进成片 |
| 工程 | `npm run dev` 可启；ffmpeg 本机转码失败有明确报错 |
| 文档 | 立项到收口文档齐全，可按 README 地图演示 |

## 4. 范围边界

### In Scope
- macOS Electron + Vite + React
- 屏幕/窗口采集、电脑摄像头（排除 Continuity）、麦克风
- Canvas 合成、MediaPipe 背景虚化（可降级）、指针/捏合缩放
- 悬浮控制条、摄像头 PiP、托盘与全局快捷键
- 本地 MP4 + JSON sidecar

### Out of Scope
- Windows / iOS / Android
- 云同步、账号、团队协作、AI 自动剪辑字幕
- 系统声 loopback（本 MVP 不做）
- 时间线非线性剪辑、美颜滤镜市场

5. 文档闭环与 GitHub 归档

## 7. 风险摘要

- macOS 屏幕/摄像头权限需重启进程才生效 → 文档与 UI 引导。
- Continuity 手机摄像头抢占 → 设备白名单仅电脑摄像头。
- MediaRecorder 默认 WebM → 强制 ffmpeg 转 MP4，失败不交付伪后缀。
- 主窗隐藏后计时节流 → 操作条本地墙钟计时。
