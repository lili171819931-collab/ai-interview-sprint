# 信息架构（IA）

## 窗口角色

| 窗口 | 何时出现 | 职责 |
|------|----------|------|
| 主录制壳 | 启动即有 | 选屏、设备开关、预览合成、壳内启停条、「更多」展开 |
| 悬浮操作条 | 录制且主窗隐藏时 | 计时、启停/暂停、摄像头/反转/复位缩放、关/收起 |
| 摄像头 PiP | 摄像头开启且 live | 监视出镜；拖动同步成片位置；单击切形；双击反转；不进成片 |
| 菜单栏托盘 | 常驻 | 显示主窗/操作条、截图、录制、退出 |

## 主壳结构（紧凑）

```text
┌─ Topbar：品牌 / 更多 / 状态胶囊 ─────────────┐
├─ Shell Rec Bar：计时 · 启动 · 停止 · 暂停 · 摄像头 · 反转 ─┤
├─ Preview：Canvas 成片预览 + selfie 监视 ──────┤
├─ 屏幕源：选择屏幕 / 截图 ───────────────────┤
└─ 设备开关：摄像头 / 麦克风 …（更多内高级项）─┘
```

## 导航原则

1. **一屏完成开录**：默认紧凑壳，不强迫三栏工作台。
2. **成片优先**：所有出镜操作最终作用在 compose layout。
3. **录制中少窗**：主窗可藏，只留操作条 +（可选）摄像头 PiP。
