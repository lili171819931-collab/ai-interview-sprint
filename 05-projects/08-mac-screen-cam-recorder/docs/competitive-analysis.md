# 竞品与定位分析：Mac Screen Cam Recorder

## 1. 一句话定位

**面向 Mac 教学创作者的本地「屏幕 + 圆形出镜」录制壳**：所见即所得合成，停录即得 MP4，数据不出本机。

## 2. 竞品地图

| 类型 | 代表 | 优势 | 缺口 | 我们的机会 |
|------|------|------|------|------------|
| 系统自带 | macOS 截屏 / QuickTime | 零安装、系统级权限 | 无圆窗合成、弱教学操作条 | 专为讲解构图 |
| 云协作录屏 | Loom | 分享链路成熟、注释强 | 默认云、偏会议异步 | 本地隐私优先 |
| 开源分享向 | Cap | 现代 UX、开源 | 云/AI 路径重，教学圆窗非核心 | 收敛到本机成片 |
| 专业直播 | OBS Studio | 场景无限强 | 学习成本高、过重 | 3 步开录 |
| 截图增强 | Snapzy 等 | 快捷键与历史体验好 | 非连续教学录屏主路径 | 吸收截图/历史心智 |
| 会议软件 | Zoom/腾讯会议本地录制 | 用户已有 | 非讲解构图、品牌水印/布局受限 | 个人讲解成片 |

## 3. 定位坐标

```text
              云协作/分享
                  ▲
                  │  Loom / Cap(云)
                  │
  重工具 ◄────────┼────────► 轻工具
           OBS    │     本产品 · 系统截屏
                  │
                  ▼
              本地隐私/成片
```

本产品落在 **本地 × 轻量 × 教学出镜** 象限。

## 4. 差异化主张

1. **构图即产品**：预览 Canvas = 成片，圆/方、位置、反转即时进片。
2. **录制中可操作**：悬浮条 + 摄像头小窗（拖动 / 单击切形 / 双击反转），且 contentProtection 不进成片。
3. **格式诚实**：不交付「后缀是 mp4 的 webm」；ffmpeg 转 H.264，失败明示。
4. **设备诚实**：只用电脑摄像头，排除 iPhone Continuity 误开。

## 5. 不争什么

- 不跟 OBS 比插件生态与多轨。
- 不跟 Loom 比团队工作区与观看分析。
- 不跟剪辑软件比时间线。

## 6. 可迁移的竞品启发（已落地）

| 启发源 | 吸收点 |
|--------|--------|
| Cap | 三步引导、录制后成功反馈、最小化主窗 |
| Snapzy | 截图历史、全局快捷键、Quick Access |
| QuickTime | 用户期望「双击就能播的 MP4」 |
