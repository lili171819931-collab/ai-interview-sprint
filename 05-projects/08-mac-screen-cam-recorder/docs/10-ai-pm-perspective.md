# AI PM 视角：本项目的取舍

## 1. 要不要 AI？

背景虚化用了 MediaPipe（经典 CV/分割），**没有**把「AI」当卖点文案。原因：

- 用户要的是清晰出镜与可控构图，不是聊天式能力。
- 虚化失败必须可关、可降级；不能阻塞开录。

## 2. 需求取舍样例

| 需求 | 决策 | 理由 |
|------|------|------|
| 云分享链接 | 不做 | 与本地信任定位冲突 |
| AI 自动字幕 | 延后 | 非开录主路径；增加模型与隐私面 |
| 圆形出镜 | 做深 | 差异化与演示记忆点 |
| 真 MP4 | 做硬 | 直接决定「能不能当课用」 |

## 3. 指标思维

先看 **首次成功出片率** 与 **成片可播率**，再看日活。工具产品没有账号时，用本地 sidecar 抽样与访谈验证。

## 4. 与作品集叙事的关系

本项目证明：PM 能定义边界、推动桌面端硬问题（权限、编码、多窗），而不是只画 Web 线框。
