```text
你是「教学录屏产品负责人」+「实时音视频合成工程师」+「macOS Electron 工程师」+「人机交互设计师」。
任务：在现有 Mac Screen Cam Recorder 上，把「静止录屏」修成真正持续录屏；并交付教学场景下的指针缩放/拉伸、摄像头小窗（圆/方、镜像、无人像字、人像清晰、实时进成片）、以及录制中可用的小巧悬浮操作条。导出 MP4 到桌面「Mac录屏」；退出必须关闭摄像头。

【项目根】
05-projects/08-mac-screen-cam-recorder/

【产品一句话】
老师边操作边讲 → 屏幕持续在动 + 指针可缩放强调 + 人像小窗实时叠进成片 → 一条本地 MP4 教学视频；录制中用小巧操作条控制启停与窗口，不必回到主界面。

【当前已知缺陷（必须先修，P0）】
1. 录屏画面静止：预览/成片像截了一张静图，鼠标移动、页面滚动、窗口切换时画面不跟着更新。
2. 摄像头小窗偶发不同步进成片，或仅预览有、成片无。
3. 小窗上可能出现「我的出镜 / 虚化 / 表情监视」等字样进成片——禁止。
4. 退出 App 后摄像头指示灯仍亮——禁止。

【本轮 Must（不可砍）】

════════════════════════════════════
P0. 持续录屏（鼠标操作时仍在录）
════════════════════════════════════
目标：从「开始」到「停止」，成片每一帧都是实时屏幕内容；用户移动鼠标、点击、滚动网页、切换窗口、打字，成片必须同步变化，禁止整段或后半段卡在首帧/某一静帧。

硬性验收：
- 选屏后预览区必须「动」：移动鼠标可见指针轨迹；滚动网页可见内容滚动。
- 开始录制后，在被录屏幕上随意操作 15–30 秒，导出 MP4 回放：操作全过程可见，不是静图。
- 录制时长 ≥ 操作时长；禁止「时间在走、画面不动」。

根因排查与修复要求（必须写进方案并落地）：
A. 屏幕轨必须持续出帧
   - getDisplayMedia / desktopCapturer 拿到的 video track 必须 live；video 元素必须挂进 DOM、muted + playsInline + 保持 play()。
   - 禁止用单张 thumbnail / 静态 ImageBitmap 当屏幕源。
   - macOS 系统选择器优先；勿在 DisplayMedia handler 里用错误源覆盖成静止源。
B. 合成循环必须稳定、不可被 React state 反复掐断
   - 合成用 requestAnimationFrame 或 requestVideoFrameCallback，依赖 refs，禁止因 layout/开关/拖动每帧重建导致 cancelAnimationFrame 连环重启。
   - 录制期间禁止改变 compose canvas 宽高（resize 会让 captureStream 卡首帧）。
C. MediaRecorder 吃的是「正在被每帧重绘的 canvas」
   - canvas.captureStream(30) + 每帧 drawImage(screenVideo)；确认 screenVideo.currentTime / readyState 在递增。
   - 若主窗口最小化：合成循环仍须在后台跑；必要时用 hidden worker/独立 offscreen canvas 或禁止因 visibilitychange 停 RAF（需实测 Electron 行为并文档化）。
D. 自录保护
   - 悬浮操作条、摄像头监视浮窗应用 setContentProtection(true)，避免录进成片造成「双小窗」或递归镜像；成片小窗只来自 Canvas 合成。
E. 回归测试清单（必须实测打勾）
   - [ ] 预览滚动网页有动效
   - [ ] 录 20s 含鼠标移动 → MP4 有指针移动
   - [ ] 录制中最小化主窗口 → 成片仍持续更新
   - [ ] 暂停/继续后画面继续动，不是停在暂停帧之后一直静

════════════════════════════════════
P1. 鼠标指针 + 网页缩放/拉伸（教学强调）
════════════════════════════════════
目标：教学时可用指针焦点做「放大/拉伸」强调，帮助观众看清被点击区域。

Must：
1. 指针可视化（成片内）
   - 可选：系统指针原样录制（默认依赖 OS 指针进屏采）+ 可选「高亮光圈/放大镜」叠加层。
   - 至少交付一种「焦点缩放」：按住快捷键或点击操作条「缩放」后，以鼠标位置为中心，对屏幕内容做局部放大（lens）或轻微透视拉伸，强调当前操作点。
2. 缩放/拉伸效果规格
   - 模式至少两种可切换：
     a) 圆形放大镜（lens）：半径可调，放大倍率 1.5x–3x；
     b) 拉伸强调（stretch）：沿焦点局部 scale，边缘柔和，避免硬切。
   - 效果只影响「屏幕层」合成，不影响摄像头小窗清晰度。
   - 开/关即时；关闭后立即恢复正常比例，无残影。
3. 控制方式
   - 悬浮操作条按钮：缩放开/关、倍率或模式切换。
   - 可选快捷键（如按住 ⌥ 临时放大）；写入 README。
4. 非目标（本轮不做）
   - 完整标注画板、激光笔路径录制后期编辑、复杂关键动画时间线。

════════════════════════════════════
P2. 摄像头小窗：实时进成片、无人像字、人像清晰、可反转、圆/方双形态
════════════════════════════════════
Must：
1. 实时同步
   - 小窗与屏幕同一时间线合成进成片；表情、眼神、口型实时更新，禁止小窗静帧。
   - 预览所见 = 成片所得（位置、大小、形态、镜像、虚化一致）。
2. 成片小窗禁止出现任何 UI 字
   - 禁止：「我的出镜」「虚化」「表情监视」「REC」角标、设备名、提示文案。
   - 监视用字只允许出现在：主界面预览装饰层、或 setContentProtection 的桌面监视浮窗（不进成片）。
   - 成片小窗仅：影像 + 可选细描边 + 可选极淡阴影。
3. 人像清晰
   - 默认：人物清晰。若开「背景虚化」：仅背景模糊，禁止整窗 CSS blur 糊脸。
   - 虚化失败自动降级清晰人像，不中断录制。
4. 反转（镜像）
   - 独立开关「水平反转/镜像」，默认开（自拍习惯）；关则为原始摄像头方向。
   - 操作条与设置区都能切换；即时生效于预览与成片。
5. 窗口形态：圆形 / 长方形 两种模式
   - 形态切换：「圆形」|「长方形（圆角矩形）」。
   - 圆形：正圆裁切；尺寸用直径。
   - 长方形：宽高比默认 4:3 或 16:9（可预设），圆角半径约 12–16px；可调短边或统一缩放。
   - 切换形态时位置尽量保持中心锚点不变；成片立即切换，无黑块残影。
   - 可拖动；松手可吸附四角/安全边距。
   - 大小：S/M/L + 滑杆；录制中可调（若性能不足，至少预览可调并文档说明）。
6. 开关
   - 摄像头出镜、麦克风、虚化、镜像、形态，均可自主开关；默认摄像头/麦可为关（用户主动开）。
   - 关摄像头 → 成片立即无小窗。

════════════════════════════════════
P3. 教学录制悬浮操作条（小巧、专业）
════════════════════════════════════
目标：录教学视频时，主窗口可最小化；屏幕一角有「简单小巧」的操作词条/按钮条，不抢镜、不进成片（contentProtection）。

形态：
- 始终置顶、可拖动、小尺寸（建议高度 ~40–48px，宽度随内容），深色半透明，圆角，中文短词，无大面板。
- 视觉：克制、工具感；禁止紫白渐变模板风、禁止一排大 emoji。

按钮/词条（Must 具备，可图标+短文案）：
1. 启动录像（未录时显示；录制中变为「录制中」状态指示）
2. 停止录像（保存到桌面/Mac录屏 MP4）
3. 暂停 / 继续
4. 窗口切换：在「主界面显示/隐藏」与「仅操作条」之间切换；或快速唤起主窗口
5. 摄像头：开/关出镜
6. 小窗形态：圆 / 方 切换
7. 镜像：开/关
8. 指针缩放：开/关（或长按提示）
9. 可选：麦克风静音切换、录制时长显示（mm:ss）

交互细节：
- 词条可做成分段控件（segment）或图标按钮 + tooltip；点击区域 ≥ 28px。
- 危险操作（停止）需明确，但不要二次弹窗打断教学（可短闪提示「已保存」）。
- 全局快捷键与操作条等价（已有 ⌘⇧⌥R/S/. 可保留并写清）。
- 操作条本身不得出现在成片中。

════════════════════════════════════
P4. 导出与生命周期
════════════════════════════════════
1. 导出：停止后生成 **MP4（H.264 + AAC）**，始终写入 `~/Desktop/Mac录屏/`（不存在则创建）。
2. 可用 FFmpeg（系统或内置）由 WebM 中间件转码；失败时有明确错误，优先仍保住成片。
3. 退出程序 / 关闭主窗口：必须 stop 所有 getUserMedia / 屏幕轨，关闭摄像头指示灯，销毁小窗与操作条窗口。
4. sidecar JSON 记录：duration、分辨率、camera shape（circle|rect）、mirrored、blur、zoom mode、路径。

【硬约束】
1. 仅 macOS；本地隐私，不上云。
2. 所见即所得：预览合成 = 成片合成。
3. 性能目标：1080p@30fps；缩放+虚化同时开时优先保流畅，可自动降缩放倍率/虚化强度并提示。
4. 权限：屏幕/摄像头/麦克风；中文引导 + 打开系统设置。
5. 不要把「系统权限已开启」和「App 内功能开关」混为一谈。

【信息架构】
- 主窗口：选屏、设备开关、历史、完整设置（形态/虚化强度/导出目录提示）。
- 录制中：悬浮操作条（主控）+ 可选 contentProtection 监视浮窗（仅自己看，不进成片）。
- 成片：屏幕（含指针与可选缩放效果）+ 无字幕小窗（圆或方）+ 麦声音。

【技术要点（必须写进作战计划）】
1. 持续出帧诊断：在开发态临时 HUD 显示 screenVideo.readyState、videoWidth、逐秒 frame counter；静止时优先查 track.muted/ended、video.paused、RAF 是否被取消、canvas 是否被 resize。
2. 合成顺序每帧：
   clear → draw 屏幕 →（可选）指针缩放层 →（可选）摄像头：镜像 → 虚化 → clip 圆/圆角方 → draw → stroke
3. 摄像头裁切：
   - circle: arc clip
   - rect: roundRect clip
4. 操作条 = 独立 BrowserWindow（frame:false, alwaysOnTop, setContentProtection(true)），经 IPC 调主渲染进程的 start/stop/toggle。
5. 缩放层：基于鼠标位置（可从主进程/本机事件或要求用户在「被录屏」上操作时用 CGEvent/轮询；若 Electron 拿不到跨屏鼠标，则采用「快捷键开关 + 屏幕中心/上次点击点」降级，并在文档标明）。
6. 模块建议：
   - src/lib/compose.ts（圆/方裁切）
   - src/lib/camera-blur.ts
   - src/lib/pointer-zoom.ts（新建）
   - electron/control-bar.html + preload（新建）
   - electron/main.cjs（窗口、contentProtection、MP4、退出释放）

【验收标准（必须实测）】
持续录屏：
1. 预览滚动网页有运动；录 20s 含鼠标移动，MP4 回放可见移动与滚动。
2. 录制中最小化主窗口，成片仍持续更新。
指针缩放：
3. 打开缩放后，焦点处有放大/拉伸；关闭后恢复；成片一致。
小窗：
4. 成片小窗实时人像，无人像字；开虚化则人清晰景虚。
5. 镜像开关即时；圆/方切换成片形态正确。
6. 关摄像头后成片无小窗。
操作条：
7. 仅操作条可完成：开始、停止、暂停、窗口切换、摄像头、形态、镜像、缩放。
8. 成片中看不到操作条与监视字。
导出与退出：
9. 停止后桌面/Mac录屏出现可播 MP4。
10. 退出后摄像头指示灯熄灭。

【非目标】
美颜商场、云分享、完整时间线剪辑、字幕轨编辑器、Windows/手机、数字人、自动生成讲稿。

【执行顺序】
Step 0：读 App.tsx / compose.ts / main.cjs / camera-blur.ts；用「frame counter」证实静止根因；写 1 页作战计划（含是否 visibility/resize/RAF 问题）。
Step 1：P0 修好持续录屏 + 录制中尺寸锁定 + 退出释媒体；实测打勾。
Step 2：P2 小窗圆/方 + 成片去字 + 镜像确认 + 实时合成回归。
Step 3：P3 悬浮操作条窗口 + IPC（启停/窗口/摄像头/形态/镜像）。
Step 4：P1 指针缩放/拉伸模块 + 操作条入口。
Step 5：MP4 导出路径确认；更新 README 与本 Prompt 验收表；列残余风险。

【输出格式】
1. 一句话：是否达到「持续录屏 + 指针缩放 + 圆/方清晰小窗（无字）+ 教学操作条 + MP4」。
2. 静止问题根因与修复证明（前后对比）。
3. 变更文件列表。
4. 验收表（上列 1–10）结果。
5. 未解决项与降级说明（尤其跨屏鼠标坐标若受限）。

【开始指令】
现在从 Step 0 执行。
先冻结并修复 P0「画面静止」，没有持续出帧之前不要堆新 UI。
Must 优先级：持续录屏 > 小窗实时无字圆/方镜像 > 操作条 > 指针缩放。
不要扩张做云、字幕编辑器、美颜商场。
```
