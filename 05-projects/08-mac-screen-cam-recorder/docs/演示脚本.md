# 演示脚本（5–8 分钟）

## 开场（30s）

「这是一个 Mac 本地教学录屏工具：屏幕 + 圆形出镜 + 麦，停录就是桌面上的 MP4。」

## 演示路径

1. **单壳启动**（15s）：指出没有多余空窗；壳内操作条。
2. **选屏**（30s）：系统选择器 → 预览动起来。
3. **摄像头**（45s）：开出镜 → 悬浮小窗；拖动、单击切方、双击反转。
4. **开录**（60s）：倒计时 → 主窗隐藏 → 悬浮条计时 → 停录。
5. **成片**（45s）：打开 `Mac录屏` → QuickTime 播放 → 对照圆窗位置。
6. **文档**（60s）：README 地图：调研→竞品→PRD→架构→验收。

## 收尾金句

「我把格式、设备、时长这些『脏活』当成产品承诺，而不是留给用户自己折腾。」
