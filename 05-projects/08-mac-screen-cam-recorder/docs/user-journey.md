# 用户旅程

## 旅程 A：第一次成功出片（Happy Path）

1. 打开 App → 看到单一主录制壳（无多余第二空窗打扰）。
2. 系统授权屏幕/摄像头/麦克风（必要时重启 App）。
3. 点「选择屏幕/窗口」→ 预览出现。
4. 打开「摄像头出镜」→ 预览圆窗 + 桌面悬浮小窗。
5. 拖动小窗到右下；单击切方；双击确认镜像方向。
6. 点「启动录像」→ 倒计时 → 录制；主窗可自动隐藏，悬浮条计时。
7. 点「停止」→ 转码 MP4 → 桌面 `Mac录屏` → QuickTime 打开验证。

## 旅程 B：录制中改出镜

1. 录制进行中，拖动悬浮摄像头窗 → 成片位置跟随。
2. 单击切圆/方；双击反转。
3. 暂停讲解无关段落 → 继续 → 停止保存。

## 旅程 C：失败可理解

| 失败 | 用户看到 |
|------|----------|
| 未选屏幕 | 操作条/主壳提示并拉起选择器 |
| Continuity 摄像头 | 自动排除或提示改用电脑摄像头 |
| 无 ffmpeg | 保存失败文案，引导 `brew install ffmpeg` |
| 权限拒绝 | 深链到系统设置 + 重启说明 |

## 情感目标

「我不需要学 OBS，也能录出像课一样的片子；而且文件双击就能播。」
