# 测试与验收报告

## 1. 测试策略

以**实机场景清单**为主（桌面采集/权限无法在 CI 完整模拟），辅以 `tsc --noEmit`。

## 2. 功能用例

| ID | 用例 | 期望 | 结果 |
|----|------|------|------|
| F1 | 选屏后预览 | 画面运动不静帧 | ✅ |
| F2 | 开摄像头 | 仅电脑摄像头；预览+PiP | ✅ |
| F3 | 单击/双击/拖动 | 切形/反转/成片位置变 | ✅ |
| F4 | 录制 15s 停 | 桌面 MP4，QuickTime 可播 | ✅ |
| F5 | 操作条计时 | 与成片时长接近（不含倒计时） | ✅ |
| F6 | 虚化开关 | 开/关/失败降级 | ✅ |
| F7 | Continuity 设备 | 列表排除或拒绝 | ✅ |
| F8 | 无屏幕点启动 | 提示并拉起选择器 | ✅ |

## 3. 兼容与环境

- macOS + Electron 37 开发态
- 依赖本机 `ffmpeg`（Homebrew）

## 4. 已知问题

- 正式签名分发未做；开发态需用户信任 Electron 权限项。
- PiP 与主轨双开摄像头时，极少数机型预览窗可能提示占用（成片主轨仍优先）。

## 5. 结论

达到面试演示与个人教学录制 MVP+ 标准；剩余项见需求冻结 P2。
