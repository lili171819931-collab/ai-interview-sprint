# PRD — Mac Screen Cam Recorder（macOS only）

## 一句话

在 Mac 上同时录屏幕、圆形/方形摄像头出镜与麦克风，实时预览合成，停止即得到桌面「Mac录屏」里的 H.264 MP4。

## 用户问题

教学/讲解录制时需要「屏幕内容 + 真人出镜 + 人声」，现有工具要么太重（OBS）、要么偏云（Loom）、要么成片格式像网页视频（WebM），且手机 Continuity 摄像头容易误开。

## 目标用户

- 独立讲师、知识创作者（主）
- 产品经理做演示回放（次）
- 工程师录本地教学短片（次）

## 范围

### Must
- 屏幕/窗口源、系统选择器
- 电脑摄像头圆/方 PiP：拖动、单击切形、双击反转；录制中悬浮小窗可操作
- 麦克风开关；倒计时；暂停/继续
- 本地 MP4（ffmpeg H.264）+ sidecar；权限引导
- 主录制壳内操作条；录制隐藏主窗时出悬浮条
- 操作条/摄像头监视窗 contentProtection，不进成片

### Should
- 背景虚化、缩放、截图与历史、托盘与全局快捷键

### Won't（本版）
- Windows、云同步、系统声、AI 剪辑

## 成功标准

1. QuickTime 打开成片：屏幕 + 出镜 + 人声。
2. 预览小窗位置/形状/镜像与成片一致。
3. 操作条显示时长 ≈ 成片时长（倒计时不计入）。
4. 未安装 ffmpeg 时失败可读，不留下伪装 MP4 的 WebM。
