# 极致 Prompt：圆形摄像头嵌入录屏 + 虚化 + 开关（macOS）

> 可整段复制给 Cursor / Claude / GPT。  
> 项目根：`05-projects/08-mac-screen-cam-recorder/`（已有 Electron MVP 可在此基础上增强）。  
> 平台锁定：**仅 macOS**。

---

```text
你是「个人录制工作室」的产品负责人 + 实时音视频合成工程师 + macOS Electron 工程师。
任务：在现有 Mac Screen Cam Recorder 上（或从零）交付以下能力——启动录制时，圆形摄像头个人小窗必须嵌入到录制屏幕画面中，与屏幕画面同一时间线同步录进成片；小窗可拖动、可调大小、人物背景虚化；摄像头 / 麦克风等用独立开关自主选择。

【项目根】
05-projects/08-mac-screen-cam-recorder/

【产品一句话】
点开始 → 屏幕 +（可选）圆形摄像头出镜 +（可选）麦克风 → 预览所见即所得 → 停止得到一条已合成的本地视频。

【本轮 Must（不可砍）】
A. 圆形摄像头嵌入并同步录制
- 开始录制后，摄像头画面以正圆形小窗叠加在屏幕内容之上。
- 必须合成进最终成片：禁止只预览有圆窗、导出却没有；禁止分轨留给用户后期拼。
- 音视频同一时间线起步；长时间录制不允许圆窗与屏幕明显漂移。
- 圆窗关闭（摄像头开关关）时，成片只含屏幕（+可选麦），不得留黑圆/残影。

B. 可拖动
- 预览区可拖动圆窗；松手可吸附四角（或边距安全区）。
- 拖动坐标相对「成片画布」计算；预览位置 = 导出位置（含 Retina 缩放一致）。
- 录制中仍允许拖动（若性能不够，至少 idle/预览可拖，并在文档标明）。

C. 大小可调
- 提供直径调节：滑杆 + S/M/L 预设（例如 140 / 200 / 280px，范围约 120–360）。
- 调节即时反映在预览与成片构图。

D. 背景虚化（人物出镜）
- 圆形小窗内对摄像头画面做人像背景虚化（bokeh）：人物清晰、背景模糊。
- 实现优先级：
  1) 优先：BodyPix / MediaPipe Selfie Segmentation / 浏览器或本地分割模型 → 前景清晰 + 背景高斯模糊后合成；
  2) 降级：整圆轻度背景感虚化不可接受时，至少提供「背景模糊强度」滑杆 + 关闭虚化开关；
  3) 禁止用整圆 CSS blur 把人脸一起糊掉冒充「背景虚化」。
- 提供「虚化开关」与「虚化强度」；关闭后为清晰原摄像头画面（仍圆形裁切）。
- 虚化失败时自动降级为无虚化并提示，不中断录制。

E. 开关按钮（自主选择）
- 必须有清晰开关（Toggle），至少包括：
  1) 摄像头出镜（开/关）
  2) 麦克风收音（开/关）+ 电平表
  3) 背景虚化（开/关）
  4) 水平镜像（开/关，默认开）
  5) 开始前倒计时（开/关）
  6) 开始后最小化本窗口（开/关，避免录进 App UI）
- 开关状态要即时生效：关摄像头 → 预览与成片立即去掉圆窗；关麦 → 成片无有效人声且无爆音。
- 设备选择：摄像头设备、麦克风设备下拉可切换。

【硬约束】
1. 隐私：本地录制/预览/导出；不上云。
2. 权限：屏幕录制、摄像头、麦克风；拒绝时有中文引导与系统设置入口。
3. 所见即所得：预览合成 = 成片合成（圆窗、虚化、位置、大小一致）。
4. 性能：开启虚化后仍尽量保 1080p@30fps；扛不住则自动降虚化强度/降分辨率并提示。
5. 导出：默认写到桌面文件夹「Mac录屏」；WebM 可接受，若易接 FFmpeg 可再转 MP4。
6. 平台：只做 macOS；不做 Windows/手机端。

【交互与视觉】
- 主界面：左（选屏/历史）+ 中（合成预览，可拖圆窗）+ 右（开关与调节）。
- 右侧「出镜与收音」分区：大号 Toggle 列表，不要把开关埋进深层菜单。
- 圆窗：正圆裁切 + 细描边；虚化开启时边缘抗锯齿。
- 录制中：悬浮条显示时长 / 麦状态 / 暂停 / 停止；可用托盘停止。
- 文案中文；避免紫白渐变模板风。

【技术要点（必须写进方案）】
1. 采集：屏幕 getDisplayMedia 或 desktopCapturer；摄像头/麦 getUserMedia。
2. 合成：Canvas/WebGL 每帧：
   - draw 屏幕
   - 若摄像头开：分割/虚化处理 → clip 正圆 → draw 到 layout(x,y,diameter)
   - canvas.captureStream + 麦音频 → MediaRecorder
3. 虚化管线单独模块（如 src/lib/camera-blur.ts），可单测/可开关。
4. 布局状态：{ x, y, diameter, mirrored, blurEnabled, blurStrength } 进 sidecar JSON。
5. 新版 macOS 勿只依赖易误报的 getMediaAccessStatus('screen')；选屏走系统选择器。

【验收标准（必须实测）】
1. 开摄像头 + 开麦 + 开虚化 → 录 20 秒 → 成片同时有屏幕、圆形人脸（背景虚化）、人声。
2. 录制前/中拖动圆窗到左上，成片位置一致。
3. 调节直径 S→L，成片大小变化一致。
4. 关闭摄像头再录，成片无圆窗。
5. 关闭麦克风再录，成片无人声。
6. 关闭虚化，圆窗内人脸与背景都清晰（仍圆形）。
7. 虚化模型加载失败时，自动无虚化继续录，有提示。
8. 预览与导出构图一致（含 Retina）。

【非目标】
美颜磨皮商店、云分享社区、完整时间线剪辑、系统声强依赖、Windows/手机、数字人。

【执行顺序】
Step 0：读现有 App.tsx / compose.ts / main.cjs；输出 1 页作战计划（虚化方案选型）。
Step 1：确认圆窗已合成进成片；补齐拖动/大小若有缺口。
Step 2：实现背景虚化模块 + 虚化开关/强度。
Step 3：把摄像头/麦克风/虚化/镜像等收成右侧清晰 Toggle 区。
Step 4：按验收清单实测；成片放到桌面/Mac录屏。
Step 5：更新 README / docs；输出变更列表与残余风险。

【输出格式】
1. 一句话：是否达到「圆窗嵌入同步录制 + 可拖可调 + 背景虚化 + 开关自主」。
2. 虚化技术方案与降级策略。
3. 变更文件列表。
4. 验证步骤与结果表。
5. 未解决项。

【开始指令】
现在从 Step 0 执行。先冻结虚化方案，再改代码。
Must 是：同步合成进成片、可拖、可调大小、背景虚化（可关）、摄像头/麦克风等开关。
不要扩张做云、标注编辑器、美颜商场。
```

## 使用方式

1. 整段复制上面 `text` 块发给 Agent。  
2. 若只增强虚化：在开头追加「只做 D 背景虚化 + E 开关整理，不动选屏逻辑」。  
3. 若机器性能弱：追加「默认虚化强度 40%，自动降级优先保帧率」。
