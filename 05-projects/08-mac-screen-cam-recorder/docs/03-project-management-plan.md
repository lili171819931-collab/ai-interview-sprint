# 项目管理计划

## 1. 方法论

轻量迭代：Prompt 驱动需求 → 可运行垂直切片 → 实机验收 → 文档回写。适合一人产品+研发的作品集节奏。

## 2. 里程碑与状态

| 里程碑 | 内容 | 状态 |
|--------|------|------|
| M0 | 立项 / 调研 / 竞品 | ✅ |
| M1 | 合成录制 MVP | ✅ |
| M2 | 虚化 / 截图历史 / 快捷键 | ✅ |
| M3 | 教学操作条 / 缩放 / 小窗壳 | ✅ |
| M4 | MP4 导出 / 时长对齐 / PiP 手势 | ✅ |
| M5 | 全项目文档打包归档 | ✅（本轮） |

## 3. 节奏

- 每日：可演示增量优先于完美抽象。
- 每轮：极致 Prompt（`docs/极致Prompt-*.md`）定义验收句，再改代码。

## 4. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 权限/重启 | 高 | 中 | UI 文案 + README |
| Continuity 误开 | 中 | 高 | 设备过滤 |
| 伪 MP4 | 中 | 高 | ftyp 校验 + ffmpeg |
| 双窗抢摄像头 | 中 | 中 | PiP ideal 降级 + 成片主轨优先 |

## 5. 沟通物

- 对内：battle-log、decisions
- 对外（面试）：README 文档地图、演示脚本、interview-story
