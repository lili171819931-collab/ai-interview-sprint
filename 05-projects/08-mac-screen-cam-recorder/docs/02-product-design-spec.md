# 产品设计说明

## 1. 设计原则

1. **所见即所得**：预览 Canvas 即成片构图。
2. **本地信任**：无账号；敏感窗 contentProtection。
3. **少窗打扰**：启动单壳；录制中才出现必要悬浮控件。
4. **手势可记**：单击切形、双击反转、拖动改位。

## 2. 关键交互规格

### 摄像头小窗（预览合成 + 悬浮 PiP）

| 手势 | 行为 |
|------|------|
| 拖动 | 更新 compose layout（吸附四角） |
| 单击 | circle ↔ rect |
| 双击 | mirrored 开/关 |

### 录制计时

- 从 `MediaRecorder.start` 起算；倒计时不计入。
- 悬浮条用墙钟本地 tick，避免主窗隐藏节流。

### 导出

- 目录：`~/Desktop/Mac录屏`
- 容器：`.mp4`（ffmpeg libx264 + aac）；sidecar `.json`

## 3. 视觉

- 深色工具壳，突出预览与红色录制态。
- 避免营销落地页式卡片堆叠；本应用是工具不是品牌站。

## 4. 无障碍与降级

- 虚化失败 → 清晰出镜继续录。
- PiP 预览抢设备失败 → 提示「成片仍有摄像头」，手势仍可用。
