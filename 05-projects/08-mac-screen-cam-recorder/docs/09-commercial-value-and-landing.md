# 商业价值与落地

## 1. 价值主张

帮 Mac 上的讲解型创作者 **更快产出可分发的本地成片**，且不出让素材控制权。

## 2. 谁付钱（假设）

| 对象 | 付费动机 |
|------|----------|
| 独立讲师 | 省 OBS 学习时间；成片直接进剪映/上传 |
| 小型培训团队 | 统一「圆窗教学」观感 |
| 企业内训（谨慎） | 内网/敏感屏不希望走云录屏 |

## 3. 可能的收费切口（未实施）

- 免费：基础录屏 + 圆窗 + MP4
- 专业：虚化增强、模板、系统声、多分辨率导出
- 团队：静默配置、品牌片头（仍可本地）

## 4. 增长假设

- 渠道：Twitter/X、小红书教学创作者、GitHub README、Product Hunt（需签名包）
- 钩子：15 秒对比视频「WebM 浏览器打开 vs MP4 QuickTime」

## 5. 落地约束

- 必须处理 notarization，否则分发摩擦大。
- 不与 Loom 正面抢协作；强调本地与教学构图。
