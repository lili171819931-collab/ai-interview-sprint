# 产品设计说明（Product Design Spec）

## 1. 信息架构总览

- 总览：智能搜索入口 + 指标 + 推荐 + 数据链 + 能力地图
- 目录：分段筛选 + 排序 + 结果视图 + 多选对比
- 详情：功能档案 + 七维评分 + 优劣势 + 来源链
- 对比：弹窗化图像对比 + 智能结论
- 来源：数据资产路径 + 抓取结果 + 工具来源映射
- 口径：评分标准 + 日更流程 + 风险说明

## 2. 视觉层级

### 2.1 语义色
- Primary（青绿）：成功、推荐、可信
- Accent（智能紫）：智能分析、搜索、焦点态
- Warning（琥珀）：限制、过期、secondary
- Danger（红）：失败、风险、inferred
- Neutral（蓝灰）：背景信息与连接线

### 2.2 文字层级
- Hero 标题：最大字号，强调价值主张
- Section 标题：模块导向
- Metric 数字：高亮 + 大字号
- Body：中等对比
- Caption：弱化说明

## 3. 关键交互

- 搜索词建议一键填充
- 更多筛选折叠，降低页面噪音
- 多选工具后固定底栏触发对比
- 对比结果弹窗支持 ESC/遮罩关闭

## 4. 图表与信息可视化

- 单柱状：品类分布、抓取成功失败
- 并排柱状：七维对比
- 雷达图：能力形态直观比较
- 数据链/流程图：可审计链路表达
- 思维导图：品类-工具全局关系

## 5. 可用性与可访问性

- 图标必须搭配文本标签
- 关键状态不只靠颜色区分
- 小屏支持横向滚动图表
- 空态提供下一步建议

## 6. 设计决策原则

1. 图表服务决策，不做装饰
2. 一屏只承载一个主要结论
3. 优先同品类比较，降低误导
4. 任何结论必须可追溯来源
