# 演示脚本（约 4 分钟）

1. **总览（40s）**  
   「这是智衡 AI Radar。首屏是品牌、雷达主视觉与今日格局。下方是**数据来源链**：公开源 → 抓取 → 校验 → 写入 → 页面，可点击看口径。」

2. **能力地图（30s）**  
   「这张思维导图不是装饰，节点都是当前 bundle 里的真实工具，点进去就是详情。」

3. **目录（30s）**  
   用图标筛选「开发者平台」→ 点开详情 → 指**来源数据链**（official 在前）。

4. **对比（40s）**  
   勾选 2 款 →「生成对比图」弹窗 → 指雷达形态 + 维度胜出标注 + 智能选型三卡。

5. **动态雷达 → 热点 → 机会简报（70s）**  
   打开「动态雷达」→ 指 **TrendRadar 热点融合**（平台状态 / AI 速览 / Top 榜）→ 可选打开本机 HTML 报告 → 再点 **BuilderPulse 今日构建建议** → `/pulse` 讲 Why now、2 小时构建与署名。

6. **来源报告（20s）**  
   打开「来源报告」→ 指数据资产路径表（bundle / report / pulse / trendradar / seed）。

7. **日更（20s）**  
   口径页看日更管道 → 强调「只更 changelog / 热点，不自动改分」→ `pulse:sync` / `trendradar:sync` 失败降级 seed。

8. **收束（20s）**  
   「我们把主观评测收成可审计字段，再用图表、来源报告、大众热点和机会简报，让发现与行动都能被追问。」
