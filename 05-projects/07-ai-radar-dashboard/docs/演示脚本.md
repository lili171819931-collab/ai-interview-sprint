# 演示脚本（约 3 分钟）

1. **总览（40s）**  
   「这是智衡 AI Radar。首屏是品牌、雷达主视觉与今日格局。下方是**数据来源链**：公开源 → 抓取 → 校验 → 写入 → 页面，可点击看口径。」

2. **能力地图（30s）**  
   「这张思维导图不是装饰，节点都是当前 bundle 里的真实工具，点进去就是详情。」

3. **目录（30s）**  
   用图标筛选「开发者平台」→ 点开详情 → 指**来源数据链**（official 在前）。

4. **对比（50s）**  
   勾选 2 款 →「生成对比图」弹窗 → 指雷达形态 + 维度胜出标注 + 智能选型三卡。

5. **来源报告（30s）**  
   打开「来源报告」→ 指数据资产路径表（bundle / report / seed）→ 点开一条公开源 URL → 看成功/失败柱状图。

6. **日更（30s）**  
   口径页看日更管道流程图 → 强调「只更 changelog，不自动改分」→ 失败不覆盖昨日。

7. **收束（20s）**  
   「我们把主观评测收成可审计字段，再用图表与来源报告让决策过程可被追问。」
