# 验收清单

- [ ] `npm install && npm run data:refresh && npm run build` 通过
- [ ] 工具目录 ≥ 30 款（四品类均有）
- [ ] `data:refresh` 能请求公开 RSS/Atom，并写入 `liveFetch` 报告
- [ ] 单路源失败不阻断整次日更；`data:refresh:offline` 可用
- [ ] 首页展示品牌「智衡」、今日看点、新鲜度徽章
- [ ] 目录筛选品类/受众/地区/集成可用
- [ ] 详情页有介绍、优劣势、来源、评分证据
- [ ] 对比页 2–4 款；不足 2 款有提示
- [ ] 对比底部有个人/工程师/企业三条建议
- [ ] 口径页展示抓取明细与来源等级
- [ ] 日更不自动改七维分数
- [ ] 总览有数据来源链与能力地图（真实数据节点）
- [ ] 结构图具备语义色（成功/警告/品类色）
- [ ] 总览/对比/来源页有柱状图 + insight 句
- [ ] 目录结果区：摘要条、排序、List/Table、多选对比底栏
- [ ] `/sources` 含资产路径表、公开源链接、抓取柱状图（无伪造 DB）
- [ ] 详情页有来源数据链
- [ ] 对比页有决策流程图与决策树
- [ ] 图标均有文字/aria-label，无裸图标
- [ ] 窄屏（≤375px）图表可横向滚动，不溢出
- [ ] 打印/截图对比页可读
- [ ] 删除或破坏 bundle 后页面降级不白屏
- [ ] 无密钥进仓
