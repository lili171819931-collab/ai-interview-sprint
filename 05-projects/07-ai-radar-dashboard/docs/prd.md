# PRD：智衡 AI Radar

## 1. 背景与问题

AI 平台与工具迭代快，选型信息散落在官宣、评测与口碑里。产品经理与工程师需要的不是「又一份 Top10」，而是**可日更、可对比、分数能追溯**的决策面板。

## 2. 用户

- AI 产品经理 / 解决方案：快速看懂同类差异
- 工程师：API / 生态 / 成本 / 地区
- 面试演示：2 分钟讲清「调研→结构化→日更→对比」

## 3. 目标

- 首屏讲清今日格局与数据新鲜度
- 每款工具有功能介绍与优劣势
- 对比维度固定，附证据与来源等级
- 日更可本地跑通；失败降级不白屏

## 4. 非目标

- 秒级价格爬虫、用户账号、评论社区
- 全球唯一排名首页大数字
- 违规抓取需登录后台

## 5. 成功指标（演示口径）

| 指标 | 目标 |
|------|------|
| 冷启动可读 | `npm i && data:refresh && dev` ≤ 5 分钟 |
| 对比可解释 | 任意分数能指到 evidence/source |
| 日更安全 | 校验失败保留昨日快照 |
| 演示时长 | ≤ 3 分钟讲完主路径 |

## 6. 主场景

打开总览 → 看今日看点 → 目录筛选 → 勾选 2–3 款对比 → 读场景建议。
