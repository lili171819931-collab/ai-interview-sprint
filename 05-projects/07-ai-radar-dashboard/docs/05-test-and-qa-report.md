# 测试与质量报告（Test & QA Report）

## 1. 测试目标

- 验证核心业务路径可用
- 验证数据可信链路与降级策略
- 验证关键页面在桌面与窄屏可读

## 2. 测试范围

### 功能测试
- 总览：搜索入口、推荐区、数据链
- 目录：筛选、排序、视图切换、多选
- 对比：弹窗、雷达/柱状、智能结论
- 来源：资产路径、源链接、抓取状态
- 口径：评分定义与流程说明

### 数据测试
- `data:refresh` 成功与失败场景
- `daily-bundle` 字段完整性
- `live-fetch-report` 状态可解释性

### 非功能测试
- 构建稳定性（`npm run build`）
- 基础可访问性（图标标签、按钮可见）
- 响应式可读性（图表可滚动）

## 3. 用例摘要

| 编号 | 场景 | 预期 |
|------|------|------|
| TC-01 | 首页加载 | Hero、指标、图表正常显示 |
| TC-02 | 目录搜索 | 输入关键词后结果收敛 |
| TC-03 | 多选对比 | 2+ 工具触发弹窗 |
| TC-04 | 来源报告 | 资产路径与链接可见 |
| TC-05 | 日更抓取 | 成功/失败状态写入报告 |
| TC-06 | 构建 | build 无错误完成 |

## 4. 当前结论

- 主流程通过，构建通过。
- 公开源抓取支持失败降级，具备可追溯性。
- 对比与来源页面具备面试演示可用性。

## 5. 遗留风险（可迭代）

- 外部公开源结构变化可能导致解析失败。
- 某些长名称在超窄屏需更细化截断策略。
- 图表智能结论可进一步接入规则引擎增强。
