## 署名要求（本仓承诺）

1. 页面与 JSON 中保留 BuilderPulse **attribution** 字段与原文链接。  
2. README / 文档持续列出上表链接，不省略作者名。  
3. 不把上游源码 / venv 整包提交进本仓；需要时用 install 脚本或外部目录。  
4. 不做 BuilderPulse / AIHOT 内容的商业转载或付费打包。
