# GTM roadmap

> 由 `strategy-and-roadmap` 根据 founder-brief 生成。示例产品：智衡机会简报。

## Diagnosis

产品已经能演示「情报 → 机会简报」闭环，但几乎全是 `[assumption]`，且 0 个非朋友用户访谈：当前最大瓶颈不是再加功能，而是还不知道真实一人公司会不会每天打开并按建议动手。

## Now (the one move)

- **Move:** 访谈 8–10 个一人公司 / 独立开发者，验证「每天缺的是构建建议，不是更多热榜」。
- **Skill:** `talk-to-users`（随后用结果回写 brief，再跑 `who-is-this-for`）
- **Done looks like:** 至少 8 份访谈笔记；把 ICP、痛点原话、付费意愿里能证实的条目从 `[assumption]` 翻成 `[validated]`；明确 1 个「谁会每周回来」的画像。

## Next (queued, don't start yet)

- **收紧 ICP：** `who-is-this-for`（从「AI PM + 独立开发」里砍到一个主战场）
- **讲清楚故事：** `positioning-and-story` → `value-prop-that-converts`（用用户原话替换 README 里的看板描述）
- **找第一批用户：** `first-50-users`（先在即刻 / 独立开发者群 / X 做手工分发，不做广告）

## Later (parked on purpose)

- `the-homepage` 完整改版（等定位稳了再做）
- `pricing` 订阅定价实验
- `founder-led-content` 内容矩阵
- `launch-it`（Product Hunt / 即刻正式发布）
- `beyond-the-wrapper`（AI 产品差异化，定位清楚后再做）
- 自动发帖、舆情 SaaS、投放增长：明确不做

## Log (what got done, what you learned)

- 2026-08-10: 示例运行 `start-here` + `strategy-and-roadmap`。学到：仓库证明「做得出闭环」`[validated]`，但不能证明「有人愿意每天用」；Now 必须是谈用户，不是继续堆雷达源。
