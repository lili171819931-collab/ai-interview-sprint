# 极致 Prompt · 智衡 AI 设计自检与功能补全

> 用途：对当前站点做设计与功能遗漏自检，并按优先级补齐。  
> 配套：`/hot` 热点分析 · `/opportunities` 机会报告 · `public/zhiheng-mark.svg` 品牌标记

---

## 角色

你是产品设计 + 前端交付一体的 AI PM。目标不是堆页面，而是让「情报 → 判断 → 机会」闭环在侧栏里可点、可解释、可演示。

## 当前主航（验收基线）

```
内容：精选 / 全部动态 / 热点榜 / 热点分析 / AI 日报
洞察：机会报告
模型：模型榜
更多：Agent 接入
```

品牌：侧栏与 favicon 使用「聚焦雷达」标记（同心环 + 扫描弧 + 中心锁定点，主色 `#2EC9B3`）。

## 自检清单（每次改版先跑）

### A. 品牌与第一屏

1. 去掉导航后，第一屏是否仍能识别这是「智衡 AI」？（有 logo 标记，不只是文字）
2. logo 是否表达「聚焦 / 锁定信号」而非装饰性光晕？
3. 暗色体系是否统一：`--ink / --panel / --signal / --amber`，避免紫光与奶油风漂移？

### B. 信息架构

1. 侧栏是否只保留演示主路径？旧页（`/radar` `/pulse` `/history` `/sources`）可保留路由但不抢导航。
2. 「热点榜」= AIHOT 精选事件热度；「热点分析」= 国内/海外平台热搜分版——两者是否文案区分清楚？
3. 「机会报告」是否明确写清：综合热点榜 + 国内外看板 + BuilderPulse 题库？

### C. 热点分析页 `/hot`（必须）

- [ ] 国内版 / 海外版可切换
- [ ] 每条展示：标题、来源平台、日期/相对时间、热度（若有）
- [ ] 标题可点：有 `url` 则跳原文；无 `url` 则自动生成搜索链接（不得留下死链）
- [ ] 页脚展示数据源 OK/失败，不假装全绿
- [ ] 视觉对齐 `page-main` 体系，不回退到旧 `container` 杂乱布局

### D. 机会报告页 `/opportunities`（必须）

- [ ] 今日主结论 + Why now + 可行动 timebox
- [ ] 三棱镜：AI 热点榜 / 国内切入 / 海外切入（带可点链接）
- [ ] 机会题库：类别标签 + 白话 + 判断 + 反方
- [ ] 可回溯到来源页（热点榜 / 热点分析 / 日报 / pulse）

### E. 数据与诚实性

1. AIHOT 数据仅个人非商业演示，页脚保留 terms 链接。
2. 公开 API 无内部热度值时，页面须注明估算口径。
3. sync 失败降级 seed，UI 标「seed 降级」。

## 执行 Prompt（复制即用）

```text
请对 05-projects/07-ai-radar-dashboard 做设计与功能自检，并补齐遗漏：

1) 品牌：确保智衡 AI 有「聚焦雷达」图标（侧栏 + favicon），核心视觉是锁定点而非装饰。
2) 功能页 /hot：国内/海外分版热点分析看板；每条含日期、来源；标题自动链接（原文或搜索兜底）。
3) 功能页 /opportunities：基于 AI 热点榜 + 国内外热点 + BuilderPulse，输出机会点分析报告（主结论、三棱镜信号、机会题库、反方）。
4) 侧栏纳入「热点分析」「机会报告」；更新 docs/ia.md 与 README 页面表。
5) 输出一份简短自检结果：已满足 / 仍缺 / 下一步唯一动作。

约束：沿用现有暗色与 --signal 体系；不引入紫光奶油风；不删除旧路由；不提交 git 除非我要求。
```

## 常见遗漏（写进回归）

| 遗漏 | 症状 | 补法 |
|------|------|------|
| 无品牌标记 | 侧栏只有文字 | BrandMark + favicon |
| 热点分析未入导航 | `/hot` 存在但找不到 | Sidebar「热点分析」 |
| 无日期/来源 | 只有标题列表 | `fetched_at` + platform meta |
| 死链 | `url` 空仍渲染 `<a href="">` | autoHref 搜索兜底 |
| 机会与热点脱节 | pulse 单独一页 | `/opportunities` 综合三源 |
| 旧布局混入 | `container` + pill 徽章堆叠 | 统一 `page-main` |

## 验收命令

```bash
cd 05-projects/07-ai-radar-dashboard
npm run hot:sync   # 可选
npm run aihot:sync # 可选
npm run pulse:sync # 可选
npm run dev        # http://localhost:3010/hot · /opportunities
```

人工点检：侧栏 logo → 热点分析切国内/海外 → 点一条外链 → 机会报告主结论与三棱镜可点 → favicon 可见。
