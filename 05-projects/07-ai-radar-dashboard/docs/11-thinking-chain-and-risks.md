# 思维链与全量风险手册

> 视角：项目专家 + 产品专家  
> 配套 Prompt：[`极致Prompt-思维链与风险专家版.md`](./极致Prompt-思维链与风险专家版.md)

## 1. 一句话定位

智衡不是 AI 工具导航站，而是**可审计的 AI 工具选型决策台**：用结构化能力画像、来源等级与场景化对比，帮助 PM/工程/采购更快形成可解释判断。

## 2. 专家思维链

### Chain 0 · 定位判断
| 问题 | 结论 |
|------|------|
| 做导航还是做决策？ | 做决策台 |
| 核心交付物是什么？ | 候选集 + 对比口径 + 来源证据 + 风险提示 |
| 什么绝不做？ | 伪科学唯一总榜、违规抓取、自动改分 |

### Chain 1 · 问题定义
| 维度 | 内容 |
|------|------|
| 谁痛 | AI PM、工程师、企业采购/解决方案 |
| 何时痛 | 选型、竞品分析、采购前评估、替换模型 |
| 替代什么 | 人工搜索、Excel、主观经验、碎片公众号 |
| 失败成本 | 选错工具、说不清理由、跨部门扯皮 |
| 最小价值 | 30 分钟内形成可解释候选与对比材料 |

### Chain 2 · AI 六闸门（本项目裁决）
| 闸门 | 裁决 |
|------|------|
| 用户价值 | 需要，但价值在“可解释选型”，不在“自动排名” |
| 模型能力 | MVP 不依赖模型评分；后续摘要可辅助 |
| 数据条件 | 仅公开 RSS/Atom/Changelog，合规可得 |
| 链路适配 | 抓取/校验/展示/降级可拆，可控 |
| 成本收益 | 人工 seed + 公开源 < 全网爬取幻觉成本 |
| 迭代节奏 | 日更动态、周更评分口径，可验证 |

**结论：不做自动总榜；做数据可信底座 + 场景对比。**

### Chain 3 · 范围冻结
**Must**：日更与降级、结构化介绍、可追溯对比、来源报告、方法口径、可演示。  
**Should**：导出报告、场景模板、埋点、企业工具库。  
**Won’t**：伪排名、登录态抓取、账号社区、秒级行情。

### Chain 4 · 数据可信链
```
seed（人工事实/评分）
  + live sources（公开动态）
  → 解析 / Zod 校验
  → 原子写 daily-bundle
  → live-fetch-report
  → freshness 降级展示
```
硬规则：RSS 不改七维分；inferred 不打极端分；校验失败保留昨日。

### Chain 5 · 决策表达链
搜索/筛选 → 多选对比 → 关键指标卡 → 雷达/柱状图 → 智能摘要 → 跨品类警告 → 看来源/详情。

### Chain 6 · 商业落地链
个人效率 → 团队报告 → 企业选型台 → 行业情报/API。  
卖点是决策流程资产，不是流量。

## 3. 决策闸门（加需求必过）

| Gate | 问题 | 失败处理 |
|------|------|----------|
| A 用户任务 | 是否服务候选/对比/核来源？ | 降级或砍掉 |
| B 可信 | 能否指出证据与来源等级？ | 禁止上线该结论 |
| C 可运维 | 失败能否降级且不毁昨日？ | 先补降级再做功能 |
| D 可演示 | 3 分钟讲清价值与风险？ | 简化交互 |
| E 商业 | 是否形成可售卖资产？ | 放入下一阶段 |

## 4. 全量风险清单

| 风险 | 影响 | 触发信号 | 缓解 | 验收 |

| 范围膨胀 | 延期 | Should 变 Must | 周会砍需求 | 非目标写进 README |

## 5. 当前已落地的缓解（对照实现）

| 风险点 | 现网/现仓应对 |
|--------|----------------|
| 脏数据覆盖 | `data:refresh` 校验失败不覆盖昨日 bundle |
| 来源不可见 | `/sources` + `live-fetch-report.json` |
| 自动改分 | 评分在 seed，抓取只合并动态 |
| 跨品类误导 | 对比弹窗风险警告 |
| 信息过载 | 目录主搜索 + 品类段 + 更多筛选折叠 |
| 双仓迷路 | PATH-MAP + ai-projects 同步路径 |

## 6. 面试可讲的三条风险

1. **数据可信**：宁可用公开源 + 降级，也不做不可审计的全网爬虫。  
2. **结论边界**：对比给场景建议，不给唯一冠军，避免产品幻觉。  
3. **交付一致**：验收清单和演示脚本约束文档必须跟代码同真相。

## 7. 下一阶段只盯的风险

- P1：无导出导致“决策材料”难复用（商业转化瓶颈）  
- P1：缺少场景模板，新用户不会提问  
- P2：企业落地缺权限/审计，无法进采购流程
