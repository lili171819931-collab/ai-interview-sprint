# 需求冻结文档（Requirements Freeze）

## 1. 用户与场景

### 目标用户
- AI 产品经理：快速做工具选型判断。
- 工程师：评估 API、生态、成本与可用性。
- 企业决策方：关注合规与稳定性。

### 核心场景
1. 在总览页快速识别“今天发生了什么”。
2. 在目录中搜索并筛出候选工具。
3. 在对比弹窗中做场景化决策。
4. 在来源报告页核查数据可信度。

## 2. Must Have（冻结）

- 页面：`/`、`/tools`、`/tools/[id]`、`/compare`、`/sources`、`/methodology`
- 数据：`daily-bundle.json`、`live-fetch-report.json`
- 日更命令：`npm run data:refresh`（含失败降级）
- 对比能力：2–4 款同台，图像化结果（雷达/柱状/建议）
- 可追溯：来源等级 `official/secondary/...` 与证据字段

## 3. Should Have

- 推荐搜索词与空态引导
- 推荐区（高分/最近更新/成本友好）
- 打印友好与演示友好视觉

## 4. Won't Have（本期不做）

- 账号体系与个性化收藏
- 需登录的数据源抓取
- 自动改写七维评分

## 5. 验收口径

- 功能验收：见 `验收清单.md`
- 数据验收：来源报告可回溯路径与 URL
- 工程验收：`npm run build` 通过
- 叙事验收：`演示脚本.md` 可在 3 分钟内完整讲述
