# 费用类目与票种字典

## 一级科目

| 代码 | 名称 | 典型销售方/关键词 |
|------|------|-------------------|
| TRAVEL | 差旅费 | 酒店、铁路、航司、机票代理 |
| TRANSPORT | 市内交通 | 滴滴、地铁、公交、停车 |
| MEAL | 餐饮/餐补 | 餐饮店 + 加班/工作餐事由 |
| ENTERTAIN | 业务招待 | 餐饮/礼品 + 客户/宴请 |
| OFFICE | 办公用品 | 文具、打印、超市办公耗材 |
| COMM | 通讯网络 | 运营商、宽带、会议软件 |
| TRAINING | 培训学习 | 培训机构、考试费、课程 |
| WELFARE | 员工福利 | 体检、团建（按制度） |
| IT | 软件设备 | 云厂商、SaaS、电子市场 |
| MARKETING | 市场推广 | 广告、物料、展会 |
| LOGISTICS | 快递物流 | 顺丰、京东物流等 |
| MEDICAL | 医药体检 | 医院、体检中心（制度允许） |
| OTHER | 其他 | 必须备注，禁止滥用 |

## 二级科目（高频）

### TRAVEL
机票、火车票、酒店、出差打车、签证、机场交通、差旅补助

### TRANSPORT
网约车（市内办公）、地铁公交、停车、加油（需制度）

### MEAL
工作餐、加班餐、团建餐

### ENTERTAIN
客户宴请、商务赠礼、活动招待、茶歇

### IT
SaaS订阅、云资源、域名、电脑配件

## 票种代码

| 代码 | 名称 | 关键字段 |
|------|------|----------|
| VAT_SPECIAL | 增值税专用发票 | 购销方税号、税额 |
| VAT_NORMAL | 增值税普通发票 | 购买方、价税合计 |
| E_VAT | 电子发票 | PDF、发票号码 |
| DIGITAL_VAT | 数电票 | 20位号码 |
| TRAIN | 火车票 | 乘车人、车次、日期 |
| FLIGHT | 机票行程单 | 乘机人、航班、舱位 |
| TAXI | 出租车票 | 时间、金额 |
| QUOTA | 定额发票 | 面额 |
| POS_RECEIPT | 小票收据 | 默认不可报 |
| OVERSEAS | 境外票据 | 汇率、翻译、特批 |

## 归类启发式

```
酒店/宾馆 + 入住信息 → TRAVEL/酒店
铁路/航空 → TRAVEL/交通
餐饮 + 客户/宴请 → ENTERTAIN
餐饮 + 加班/工作餐且无客户 → MEAL
文具/办公耗材 → OFFICE
云/SaaS → IT
无法判断 → OTHER + low confidence + 强制确认
```

## 易混淆对

| 容易混 | 判别要点 |
|--------|----------|
| 招待 vs 餐补 | 是否有外部对象/商务目的 |
| 差旅打车 vs 市内交通 | 是否落在出差行程日内 |
| 团建 vs 招待 | 参与者是否主要为内部员工 |
| 福利 vs 办公 | 是否个人消费属性更强 |
