# USAGE_GUIDE

## 1. 入口

- Notion 顶层页面：`AI Product Manager Career OS`
- 首页：`01｜Career Dashboard`

## 2. 日常使用循环

```text
每周一开始：查看 Career Dashboard 当前目标
每天：在 Daily / Weekly Execution 记录任务
学习：完成 Learning Roadmap 条目 → 沉淀到 Knowledge Base → 关联项目
项目：完成 Projects 条目 → 更新 Stage 与 Completion Rate
作品：项目闭环后 → 更新 Project Portfolio → 写 Case Study
求职：目标 JD → Job Tracker → Resume Bullets → Interview Questions → STAR Stories
每周日：Weekly Review 复盘并更新下周计划
```

## 3. 项目闭环检查

一个项目只有完成以下才算闭环：

```text
PRD → Prototype → Demo → GitHub → Architecture → Evaluation → Metrics → Case Study → Resume Bullet → Interview Story
```

## 4. 求职漏斗

```text
目标公司 → 职位 → JD 分析 → 能力匹配 → 简历定制 → 投递 → 笔试 → 面试 → Offer
```

## 5. 优先级规则

- 能帮助做项目 > 知识积累
- 能证明能力 > 资料收集
- 能写进简历 > 学习打卡
- 能在面试讲 > 形式完整
- 能获得 Offer > 系统漂亮
