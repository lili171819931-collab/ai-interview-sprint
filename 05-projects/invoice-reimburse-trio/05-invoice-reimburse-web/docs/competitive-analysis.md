# 竞品与定位分析：票易报

## 1. 一句话定位

**面向中小团队的「可解释 AI 报销工作台」**：识别提效，规则保真，单据闭环。

## 2. 竞品地图

| 类型 | 代表 | 优势 | 缺口 | 我们的机会 |
|------|------|------|------|------------|
| 传统费控 | 每刻 / 合思 / Concur | 审批流完整、财务认可 | 重、贵、配置长 | 轻量 MVP + 可解释 AI |
| 票面识别工具 | 各类 OCR SaaS | 抽字段准 | 停在识别，缺报销闭环 | 识别只是 Stage 2 |
| 通用 AI 对话 | ChatGPT 等 | 入口低 | 无状态机、难审计、易幻觉 | 事实层与合规层锁死 |
| Agent 办公 | WorkBuddy | 对话出报销包快 | 偏个人生产力，弱多人审批 | Web 补齐团队协作 |
| 编程 Agent | Cursor / Codex | 强工程能力 | 不是办公报销域 | 非直接竞品；可借鉴 Agent 流水线 |

## 3. 与 WorkBuddy / Cursor / Codex 的关系（产品叙事）

| 产品 | 本质 | 对报销场景 |
|------|------|------------|
| WorkBuddy | 办公 Agent | 适合个人快速整理票据产物 |
| Cursor | AI IDE | 不服务财务报销主路径 |
| Codex | 工程 Agent | 不服务财务报销主路径 |
| **票易报** | B 端报销系统 | 多角色、可审计、可审批 |

结论：WorkBuddy 与票易报是 **同源能力的不同载体**（Agent 包 vs Web 系统），不是互相替代；Cursor/Codex 提供的是工程生产力参照，不是报销竞品。

## 4. 差异化主张

1. **可信优先于聪明**：先保证金额与合规可审计，再谈生成体验  
2. **情景模式产品化**：差旅/招待/月结不是藏在 Prompt 里，而是用户可选手势  
3. **驳回重提一等公民**：把财务真实世界的失败路径做成 Mode F  
4. **双形态资产**：同一套类目/CoT，既能做 Skill，也能做 Web（作品集完整度）

## 5. 不争什么

- 不跟巨头比审批流完整性（先验证提效与可信）  
- 不跟纯 OCR 比识别 leaderboard（比端到端一次通过率）  
- 不跟通用 Agent 比「什么都能做」（只做报销做深）
