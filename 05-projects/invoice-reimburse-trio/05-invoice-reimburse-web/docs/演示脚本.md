# 演示脚本

## 30 秒

1. 用 `lili@demo.com` / `demo123` 登录  
2. 打开「2026年8月上海客户拜访差旅」  
3. 看四张票的绿/黄/红状态与汇总金额  
4. 右侧阅读审批摘要  

## 2 分钟

1. 新建报销单，勾选 B+C+D，填写事由  
2. 上传一个名为 `hotel-demo.pdf` 的任意文件（触发酒店 Mock）  
3. 再上传 `receipt.jpg`（触发小票拒报）  
4. 点开待确认票，改购买方/金额后「保存并重跑合规」  
5. 提交审批 → 退出 → 用 `manager@demo.com` 登录 → 通过或驳回  
6. 若驳回，点「驳回重提」进入 Mode F 修订稿  
7. 导出 CSV / 摘要
