# 07 · 微迹商业方案（第一轮诊断）

> 依据：[`极致Prompt-微迹商业价值专用版.md`](./极致Prompt-微迹商业价值专用版.md)  
> 结论先行：**Conditional Go**（有条件继续）  
> 条件：90 天内只验证「窄切口留存 + 一个付费点」，不扩成习惯大平台。

---

## 0. 一票否决审查（值不值得做）

| # | 审查项 | 判定 | 证据逻辑 |
|---|--------|------|----------|
| 1 | 真痛点 | **过（弱通过）** | 「想养成但做不到」真实；但多数人用备忘录/群打卡凑合。微迹的增量是**更低摩擦 + 连续反馈**，不是新需求。 |
| 2 | 频次 | **过** | 打卡天然日频，足以支撑留存钩子；问题在付费频次，不在使用频次。 |
| 3 | 支付意愿 | **风险项** | 纯打卡工具 C 端付费意愿弱（替代免费）。付费必须绑在**结果感/陪伴/AI 复盘/身份**上，不能只卖「能打卡」。 |
| 4 | 微信生态 | **过** | 分享卡片、订阅消息、社群、搜一搜都适配；当前产品几乎未用生意能力。 |
| 5 | 壁垒 | **暂无 → 可长** | 本地打卡无网络效应。可进化路径：个人数据资产 → 周复盘 → 社群/教练关系链。 |
| 6 | 单位经济 | **有条件为正** | 低 CAC（社群/内容）+ 低客单会员可算平；投流大概率算不过。 |
| 7 | 合规 | **可控** | 避开医疗功效；虚拟支付走正确类目；订阅消息防骚扰。 |

**否决掉的错误方向**：大而全习惯平台、社交排行榜烧钱获客、AI 代打卡、重计划系统。

**若商业化完全卡死时的 2 个替代切口（仍复用资产）**：  
① 面向「习惯教练/社群主理人」的 B 端打卡看板（他们付费）；  
② 「21 天微习惯挑战」活动产品（按期收费，不做永久工具订阅）。

---

## 1. 一句话定位

**保持并强化原定位，不改赛道：**  
微迹 = 用 10 秒完成一次微习惯打卡，用连续天数与每周复盘证明你在变好。

**商业化补充句（对内）：**  
免费打卡建立日频习惯；付费买「看得懂的进步」与「不被打断的节奏」（周复盘 + 提醒 + 主题挑战）。

---

## 2. 目标用户画像（含付费动机）

### 主用户（使用方，P0）
- **谁**：25–40 岁，想变好但讨厌重工具的职场人/宝妈/学生  
- **场景**：碎片时间完成超小动作  
- **付费动机（弱→可培养）**：不怕免费打卡；愿为「别断签提醒」「每周看懂自己」「主题挑战证书/社群压力」付小额钱  
- **不付费信号**：只用 3 天、从不看记录、拒绝任何通知

### 次用户（付费方候选，P1）
- **习惯教练 / 知识社群主理人**：需要给学员轻量打卡工具  
- **付费动机**：省得用表格；要完课率与可导出数据

### 非目标
- 健身硬核玩家、重度 GTD 用户、要社交攀比排行的人

## 3. 核心价值主张（Before / After）

| | Before | After（微迹） |
|--|--------|----------------|
| 行动成本 | App 重、步骤多、计划焦虑 | 10 秒打卡，模板即用 |
| 反馈 | 做完没感觉 / 群里吼一嗓子 | 今日进度 + 连续天数即时反馈 |
| 回顾 | 不知道这周怎样 | （增强）一页周复盘：完成率、断点、下一步一个建议 |
| 坚持 | 靠意志或群监督 | 轻提醒 + 可选挑战，不靠羞辱式打卡 |

**首次 60 秒必须感知**：空状态一句人话 → 选模板 → 第一次打卡成功反馈（已有）。  
**商业化增强**：第 7 天触发「解锁本周复盘」预告，形成期待，而不是第 1 天推销会员。

## 4. 商业模式画布（精简）

| 模块 | 选择 |
|------|------|
| 价值主张 | 极轻打卡 + 可理解的进步 |
| 用户 | C 端个人为主；教练/社群为辅 |
| 渠道 | 微信社群、公众号、分享卡片、搜一搜「微习惯打卡」 |
| 收入（排序） | ① C 端会员/周复盘增值 ② 主题挑战付费 ③（后）教练版 SaaS |
| 成本 | 小程序维护、（后）云与模型调用、内容运营；早期几乎无投放 |
| 关键资源 | 打卡数据、模板库、品牌「轻」 |
| 关键活动 | 打卡产品迭代、周复盘、挑战运营、社群冷启动 |

**付费方 vs 使用方**：默认同一人（C）。B 端出现时，付费方=教练，使用方=学员（双边，后置）。

**定价建议（假设，待验证）**
- 免费层：今日打卡 + 记录 + ≤7 习惯（对齐现网）  
- 付费触发：连续打卡 ≥7 天 或 主动点「生成周复盘」  
- 锚点：¥6.6 / 周 体验 或 ¥18–25 / 月；年费 ¥128 作锚  
- 挑战：¥9.9–19.9 / 21 天营（含社群，人工可先外包主理）

**收入公式**  
`收入 ≈ 月活 × 付费转化率 × ARPPU × 付费持续月数`  
早期靠转化与持续，不靠砸流量。

## 5. 产品增强清单（相对现有代码）

### P0（90 天内必须验证）
| 项 | 动作 | 改代码？ |
|----|------|----------|
| 账号与云同步（最小） | 微信登录 + 云开发/自建，同步 habits/checkIns | 是，新存储层 |
| 订阅消息 | 「今日还未打卡」温和提醒（可关） | 是 |
| 分享卡片 | 今日完成/连续天数结果海报（工具结果型分享） | 是 |
| 周复盘 v0 | 规则引擎周报（非大模型也可先做）+ 可选 AI 润色 | 是，新页 |
| 付费墙实验 | 周复盘详情锁 / 提醒高级设置锁（二选一做主实验） | 是 |

### P1
- 主题挑战（21 天包）  
- 数据导出  
- 简单「成就」但不进首屏  

### P2
- 教练后台  
- 视频号内容矩阵  
- 广告（一般不优先，损「轻」品牌） |

### Won’t
- 代打卡、排行榜羞辱、复杂计划、首屏统计墙、医疗功效宣称

**标注**：本地-only **会卡死**会员与多设备；上云触发条件=开始做付费或提醒。在此之前可用「导出备份」过渡，但不能支撑商业化。

## 6. 关键用户旅程（含转化节点）

```
进入小程序
  → 空状态创建习惯（模板）          [激活]
  → 首次打卡成功反馈               [Aha · 60s]
  → D1–D7 每日打卡 / 订阅消息       [留存]
  → D7 推送「本周复盘已生成」       [付费触发点 A]
  → 查看复盘（免费看摘要 / 解锁完整）[转化]
  → 分享「连续 N 天」卡片给好友     [获客]
  → 下月续费或参加挑战营           [复购]
```

关键路径步数：  
- 打卡：≤ 2 步（进今日 → 打卡）— 保持  
- 付费：≤ 3 步（复盘入口 → 看价值 → 支付）— 目标 N=3  

---

## 7. 增长飞轮（文字闭环）

1. **打卡结果**产生「连续天数/今日完成」  
2. → 生成**可分享的结果卡片**（身份+工具结果，非金钱拉人）  
3. → 新用户低摩擦完成首次打卡（模板）  
4. → 日频使用沉淀**个人数据**  
5. → **周复盘**让数据变「看得懂的进步」→ 提高 D7/D30  
6. → 留存用户更常分享结果 & 更可能付费解锁复盘  
7. → 回到 1  

辅轮（30 天后）：公众号周复盘精选内容 → 搜一搜/关注 → 回小程序。

## 8. 90 天验证计划

### 核心假设（必须可证伪）
H1：用户愿意为「周复盘/提醒」付 ¥15+/月（转化 ≥ 2% 于 D7+ 活跃）  
H2：结果分享卡能带来 K≥0.3 的受邀访问（每活跃用户每月）  
H3：D7 留存 ≥ 25%（周活/新装）在无投放社群冷启动下可达  

### 0–30 天：能留下来吗？
| 实验 | 做法 | 成功标准 |
|------|------|----------|
| 冷启动 | 3 个种子社群 + 好友体验版，目标 100 人 | ≥100 打开；≥40% 完成首次打卡 |
| 留存 | 上订阅消息（可选）+ 连续天数强化 | D7 ≥ 25% |
| 分享 | 上结果分享卡 | ≥15% 打卡用户产生分享点击 |

**失败信号**：首次打卡率 &lt; 30% 或 D7 &lt; 15% → 先改激活/提醒，不做付费。

### 30–60 天：肯付钱吗？
| 实验 | 做法 | 成功标准 |
|------|------|----------|
| 付费墙 A/B | A=完整周复盘收费；B=高级提醒收费 | 任一路径付费转化 ≥ 2%（对 D7 活跃） |
| 价格 | ¥6.6 周 vs ¥18 月 | 选出 ARPU 更高且投诉低的 |

**失败信号**：转化 &lt; 0.5% 且访谈无「愿付」→ pivot 到挑战营或 B 端教练版。

### 60–90 天：能复利吗？
| 实验 | 做法 | 成功标准 |
|------|------|----------|
| 飞轮 | 分享带来新客占比 | ≥20% 新客来自分享 |
| 复购 | 月会员次月留存 | ≥40% |
| 内容 | 公众号 8 篇微习惯内容 | 单篇进小程序 ≥ 50 UV（早期） |

**决策阈值**
- H1∧H3 成立 → **Go** 加深会员与复盘  
- H3 成立但 H1 不成立 → **Conditional** 转挑战营/B 端  
- H3 不成立 → **No-Go** 停 C 端订阅，资产改为作品集/其他切口

## 9. 单位经济粗算（假设透明）

| 假设项 | 数值 | 说明 |
|--------|------|------|
| CAC | ¥0–3 | 早期社群/分享；不含投流 |
| 付费转化（D7 活跃） | 2% | 待验证 |
| ARPPU | ¥20 / 月 | 会员 |
| 付费持续 | 2.5 月 | 早期保守 |
| LTV | ¥50 | 20×2.5 |
| 毛利率 | 70–85% | 数字商品；若上 AI 调用则降至 ~60% |
| 回本 | 即时–1 周 | 因 CAC 极低；投流则另算 |

**投流敏感**：若 CAC=¥30，则 2%×¥50 撑不住 → **禁止早期投流**。

## 10. 风险与不做清单

### Top3 风险与对冲
1. **工具免费心态强** → 付费绑复盘/挑战结果，不绑基础打卡  
2. **本地数据无法支撑会员** → P0 最小云同步；未上云不做支付  
3. **提醒变骚扰导致卸载** → 默认少提醒、易关闭、文案不羞辱  

### 不做清单
大平台、排行羞辱、代打卡、重计划、首屏运营杂讯、医疗承诺、早期信息流广告、未验证就上教练复杂后台。

---

## 11. 最终推荐

# Conditional Go

**理由**  
- 打卡闭环与日频成立，微信生态适配好，作为「轻习惯」切口值得继续。  
- 但**纯打卡难收费**、**本地-only 卡住商业化**、**尚无增长飞轮**——因此不能无条件 All-in。  
- 90 天只准验证：留存门槛 + 单一付费点 + 分享获客；达成则升为 Go，否则 pivot 到挑战营或 B 端。

## 12. 下周就能开工的 5 个工程任务

1. **数据层**：设计 `userId` + 云同步协议，迁移 `weiji_store_v1`（兼容本地导入）  
2. **微信登录**：接入后写入用户；未登录仍可本地用，登录后合并  
3. **分享卡片**：今日完成/连续天数 `onShareAppMessage` + 海报画布  
4. **周复盘 v0 页**：纯规则计算（完成率、断档日、最长连续）不依赖大模型  
5. **订阅消息**：一套「今日未打卡」模板，设置页开关；埋点打开率/退订率  

（支付与付费墙放在任务 4 验证有阅读之后，作为第 2 周紧随项。）

## 文末仍可追问的 5 个关键问题（不阻塞本轮）

1. 你更想先做成 **C 端会员作品** 还是 **面试作品集叙事**？（会影响是否真接支付）  
2. 能否拿到 1–3 个现成社群做冷启动？规模各多少人？  
3. 对 AI 周复盘：接受先做规则版，还是必须第一期就上大模型？  
4. 月预算上限（云 + 域名 + 支付费率 + 可选投放）？  
5. 是否有可合作的习惯教练/主理人愿意试 B 端？
