# 06 · 验收清单与演示脚本

## 1. 功能验收（Must）

- [ ] 空状态可见，CTA 可进入创建
- [ ] 模板一键填入并可保存
- [ ] 自定义名称必填校验（空/超长）
- [ ] 今日列表展示活跃习惯
- [ ] 打卡成功：态变 + 进度变 + Toast（连续天数文案正确）
- [ ] 取消打卡需确认，确认后重算
- [ ] 记录月历高亮有打卡日；点日见明细
- [ ] 详情可改名/颜色并保存
- [ ] 归档后今日消失；删除后记录级联清理
- [ ] 第 8 个活跃习惯被拦截
- [ ] 存储失败有提示（可模拟只读/异常时）

## 2. 体验验收

- [ ] 首屏无运营杂讯
- [ ] 创建 ≤ 2 步可保存
- [ ] 打卡主操作一眼可见
- [ ] 文案短、不鸡汤
- [ ] 真机预览可用

## 3. 分发 / 上线验收

- [ ] 正式 AppID 可上传
- [ ] 体验成员可扫码进入
- [ ] （正式）审核材料齐全，发布后主路径可走通

## 4. 演示脚本

### 30 秒

空状态创建「喝水 1 杯」→ 打卡看进度与连续天数 → 切到记录看今日高亮。

### 2 分钟

再加一个模板习惯 → 完成今日全部 → 详情看 streak 文案 → 取消一次打卡观察重算 → 归档一个习惯。

### 面试 90 秒钩子

见 [`interview-story.md`](interview-story.md)。

## 5. 已知限制（对测试者透明）

- 数据仅本机，换手机不同步  
- 无提醒推送  
- 无补打卡  
- 无云开发账号体系
