# 04 · 设计系统（品牌 / 视觉 / 组件 / 文案）

## 1. 品牌

| 项 | 内容 |
| --- | --- |
| 名称 | 微迹 |
| 英文 | Weiji |
| 气质 | 轻、小、即时反馈；不鸡汤 |
| 字体 | 正文 PingFang；品牌名可用宋体字重强调 |

## 2. 色彩变量

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-brand` | `#1F7A6B` | 主色 · 松柏绿 |
| `--color-brand-deep` | `#145A4F` | 标题/强调字 |
| `--color-accent` | `#E39B6B` | 暖杏点缀 |
| `--color-ink` | `#1C2A26` | 正文 |
| `--color-muted` | `#6B7872` | 次级信息 |
| 氛围底 | `#DCEEE9 → #EEF5F2` | 青绿层次，避免纯平白 |

**刻意避开**：紫白渐变套路、奶油衬线+陶土套路、报纸排版套路。

## 3. 组件最小集

| 组件 | 职责 |
| --- | --- |
| `progress-header` | 今日进度与完成态文案 |
| `habit-check-card` | 列表项 + 打卡按钮 |
| `empty-state` | 首次引导 |
| HabitForm（创建/详情页内） | 模板与字段 |
| Calendar（记录页内） | 月历热力 |

## 4. 动效意图（≥3）

1. 打卡成功：按钮态切换 + Toast + 可选短震动  
2. 进度条 width 过渡  
3. 空状态光球轻微 pulse / 页面 fade-in  

## 5. 文案语气

| 场景 | 文案 |
| --- | --- |
| 空状态 | 先定一个小到不可能失败的习惯 |
| 打卡成功 | 搞定。今日 +1 / 搞定 · 连续 N 天 |
| 全部完成 | 今天的小事都完成了 |
| 达上限 | 先专注最多 7 个习惯 |

## 6. 实现入口

- 全局样式：`app.wxss`  
- 页面：`pages/*`  
- 组件：`components/*`
