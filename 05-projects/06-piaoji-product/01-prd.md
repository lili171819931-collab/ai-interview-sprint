# 01 · PRD：票迹 Piaoji

## 定位

| 项 | 内容 |
| --- | --- |
| 品牌 | 票迹（Piaoji） |
| 一句话 | 把散落在邮箱和相册里的发票，自动收齐、识别、对上账单，一键生成 HR 能收下的报销包 |
| 形态 | 微信原生小程序（MVP：mail/OCR 默认 mock，可切换 cloud） |
| 成功标准 | 可演示闭环 + Case01–15 + HR 包字段齐全 + 合规可解释 |

## 目标用户

| 角色 | 诉求 |
| --- | --- |
| 员工（使用方） | 少翻邮箱/相册，少填表，一次过 HR |
| HR/财务（验收方） | 明细可抽查、附件齐全、风险可见 |
| 企业管理员（付费方候选） | 制度可配、抬头/餐标/超期可控 |

## Must / Should / Won’t

**Must**  
邮箱 mock 同步、OCR mock、品类/情景、票账匹配、合规引擎、按情景拆单、HR 导出预览（说明+CSV+ZIP/manifest）

**Should**  
模糊票校对、招待补全、重置演示、思维链「处理依据」

**Won’t（MVP）**  
真税务验真生产对接、企业微信审批流、银企直联、自动换汇、复杂 BI、付费墙 UI

## 核心价值（Before / After）

| | Before | After |
|--|--------|--------|
| 收票 | 邮件/相册翻找 | 一键同步 + 上传 |
| 填表 | 手工抄发票号金额 | OCR 结构化 + 可编辑 |
| 对账 | 脑补哪笔支付 | Top3 匹配建议 |
| 过审 | 被 HR 打回重交 | 风险前置拦截 + 标准报销包 |

## 北极星（产品）

**一次导出通过率**（无 error 即可 ready）与 **人均提交耗时（≤3 分钟 / 10 票内）**。
