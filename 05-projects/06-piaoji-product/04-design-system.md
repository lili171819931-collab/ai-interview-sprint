# 04 · 设计系统（票迹）

## 品牌

| 项 | 值 |
| --- | --- |
| 中文名 | 票迹 |
| 英文 | Piaoji |
| 语感 | 票有迹可循；财务可信、冷静 |
| 主色 | `#0F4C5C` |
| 强调 | `#D97706`（风险/待办） |
| 成功 | `#0F766E` |
| 危险 | `#C2410C` |

## 视觉红线

- 避免紫白渐变、奶油陶土衬线、报纸密排  
- 卡片克制；金额 tabular nums：`¥1,280.00`  
- 动效：同步完成、识别成功、导出成功（Toast + 状态切换即可）  
- 文案像同事工具，不鸡汤  

## 组件最小集

`empty-state` · `invoice-card` · `risk-tag`

## 文案样例

- 空状态：「同步邮箱或上传发票开始报销闭环」  
- 拦截：「招待超额：上限 ¥1600（4人×餐标）」  
- HR 说明模板：申请人 / 笔数 / 合计 / 风险摘要（见 `utils/export.js`）
