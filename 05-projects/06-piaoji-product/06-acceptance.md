# 06 · 验收与演示脚本

## 验收清单

- [ ] 游客/正式 AppID 可编译  
- [ ] 同步邮箱：入库 >0；重复票跳过  
- [ ] 详情页：风险 + 匹配 + 思维链  
- [ ] 关联/跳过/校对/补全招待可用  
- [ ] 拆单：正式包与风险包分离  
- [ ] ready 可导出；blocked 不可导出  
- [ ] 可复制 HR 说明与明细 CSV  
- [ ] 无密钥入库  

## 案例抽检

C01 ready · C02 over_cap · C04 duplicate · C07 overdue · C11 passenger · C13 personal_title

## 演示脚本

**30 秒**：同步 → 点票关联 → 拆单 → 导出复制说明  

**2 分钟**：+ 招待拦截 + 模糊校对 + 制度页  

**5 分钟 HR 视角**：核对明细字段（发票号/附件名/风险）与 ZIP 命名
