# 05 · 本地 → 体验版 → 正式上线

> 详细勾选清单亦见源码 `docs/体验版上传检查清单.md`

## 1. 本地

1. 克隆 `ai-projects`，打开 `products/piaoji-mini`  
2. 微信开发者工具导入；AppID 可用游客模式（仅自测）  
3. 编译跑通：  
   - **拍照录入 / 相册上传**（收票箱或工作台；真机预览更稳）  
   - 同步邮箱 → 拆单 → 导出  
4. 我的 → 重置演示数据（回归用）  

**配置注意**：`app.json` 的 `requiredPrivateInfos` **只能**填定位类 API；相机/相册走 `permission.scope.camera` + `wx.chooseMedia`，不要把 `chooseImage`/`chooseMedia` 写进 `requiredPrivateInfos`（否则模拟器启动失败）。

## 2. 体验版（给其他人使用）

1. 使用**正式 AppID**（私有配置，不进 Git；测试号/`touristappid` **不能上传**）  
2. 开发者工具右上角 **上传** → 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com/) → **管理 → 版本管理** → **选为体验版**  
3. **成员管理 → 体验成员** → 添加对方微信号（对方需确认）  
4. 下载/发送 **体验版二维码**（不是普通网页链接；未加白名单无法打开）  
5. 体验成员按 `06-acceptance.md` 脚本验收（含拍照录入）  

**边界**：游客/测试号不能分发；未加成员无权限；更新需重传并重选体验版；GitHub 更新 ≠ 微信体验版更新。

## 3. 正式版

1. 提交审核（类目选工具/效率或企业相关，按账号类目）  
2. 审核通过后发布  
3. 迭代：改代码 → 上传 → 体验验证 → 再提审  

> GitHub 更新 ≠ 微信侧更新。
