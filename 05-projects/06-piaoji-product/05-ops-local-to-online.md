# 05 · 本地 → 体验版 → 正式上线

> 详细勾选清单亦见源码 `docs/体验版上传检查清单.md`

## 1. 本地

1. 克隆 `ai-projects`，打开 `products/piaoji-mini`  
2. 微信开发者工具导入；AppID 可用游客模式  
3. 编译跑通：同步邮箱 → 拆单 → 导出  
4. 我的 → 重置演示数据（回归用）

## 2. 体验版

1. 使用正式 AppID（私有配置，不进 Git）  
2. 上传版本 → 公众平台选为体验版  
3. 添加体验成员 → 发体验码  
4. 体验成员按 `06-acceptance.md` 脚本验收  

**边界**：游客 AppID 不能分发；未加成员无权限；更新需重传并重选体验版。

## 3. 正式版

1. 提交审核（类目选工具/效率或企业相关，按账号类目）  
2. 审核通过后发布  
3. 迭代：改代码 → 上传 → 体验验证 → 再提审  

> GitHub 更新 ≠ 微信侧更新。

## 4. Provider 切换（上线前规划）

| 能力 | MVP | 上线增强 |
| --- | --- | --- |
| 邮箱 | mock | OAuth / 应用密码 + 云函数拉取 |
| OCR | mock | 腾讯云/自研识别 + 字段置信度 |
| 验真 | verifyStatus 占位 | 税务接口 / 第三方验真 |
| ZIP 二进制 | 结构预览 + CSV 复制 | 云函数打包临时链 |

密钥与 AppSecret **永不进仓**。
