        关于本项目
        
      
        
        
        Goal Compiler · 诉求拆解平台
        
        
        把一段模糊想法，编译成一份「机器可直接执行、人类可直接验收、AI 可连续自主工作数小时」的专家级 Goal Task Specification。
        
        
          
          
        • 完整思维链结构化输出：14 个推理节点，可学习、可导出。
          • 
          
        • 最终 Goal 可人工编辑：支持复制、下载、存草稿、历史恢复。
          • 
          
        • 内置竞品分析：爬取 GitHub / Hacker News + 精选库，产品总监视角输出定位矩阵、SWOT、差异化建议。
          • 
          
        • 商务高效简约设计：零框架、本地运行、数据不出本地。
          • 
        
        
        
        技术栈
        
        
        Node.js（零第三方依赖）服务端 + 原生 JS/CSS 前端。编译引擎为规则模板 + 领域知识库，可离线运行。
