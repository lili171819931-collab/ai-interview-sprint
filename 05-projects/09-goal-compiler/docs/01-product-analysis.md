# 01 · 产品分析（PRD 摘要）

## 1. 产品定位

**Goal Compiler 诉求拆解平台**：把一段模糊想法，编译成「机器可直接执行、人类可直接验收、AI 可连续自主工作数小时」的专家级 Goal Task Specification。

一句话：**给 AI Agent 用户的「目标编译器 + 思维链教练」**。

## 2. 目标用户与场景

| 用户群 | 场景 | 核心痛点 |
|--------|------|----------|
| Claude Code / Codex / Cursor 重度用户 | 想给 Agent 下达复杂任务 | 说不清目标，Agent 反复跑偏 |
| 产品经理 / 创业者 | 把模糊 idea 转成可执行任务书 | 需求拆解不系统、验收无标准 |
| AI 学习人群 | 想学会「如何拆解目标」 | 只看结论学不会方法 |
| 企业团队 | 项目流程标准化 | 任务书格式不统一、无沉淀 |

## 3. 核心问题（Problem Statement）

1. Agent 任务失败的 60%+ 源于**目标不清晰 / 边界不明确 / 验收缺失**；
2. 现有 Skill/工具**只给结果不给过程**，用户无法学习与校验；
3. 生成的 Goal 往往**不可编辑、不可追溯、不可复用**。

## 4. 产品价值主张

- **对执行者**：一份可直接粘贴 `/goal` 的、带防作弊验收的、可断点续跑的任务书。
- **对领导者（用户）**：可视化思维链 + 可编辑目标资产 + 版本历史。
- **对学习者**：14 步完整思维链结构化输出，学会「怎么拆目标」。
- **对决策者**：内置竞品情报台，产品总监视角的定位矩阵 / SWOT / 差异化建议。

- [x] ⑨ 最终 Goal Prompt（20 段）可人工编辑
- [x] 完整思维链 14 节点结构化展示 + 导出 MD/JSON
- [x] 补充建议「你没考虑到的方向」

## 6. 成功标准（产品侧）

1. 用户输入任意模糊想法，5 秒内得到结构化编译结果；
2. 生成 Goal 可直接复制到 Claude Code `/goal` / Codex Goal Mode；
3. 思维链可完整导出，且「无思维链」用户能读懂；
4. 竞品分析一次检索覆盖 ≥3 个数据源，产出产品总监级建议。
