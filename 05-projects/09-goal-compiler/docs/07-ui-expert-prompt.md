# 07 · UI 专家优化：极致设计 Prompt 与执行记录

> 本页记录「顶级 UI 专家」视角生成的**极致描述设计 Prompt**（可直接复用于任何深色商务科技产品），
> 以及在本平台 v8 中的实际执行结果。

## 一、极致设计 Prompt（自生成）

```text
# ROLE
你是一名世界级 UI/UX 设计专家，擅长「商务科技深色」风格的 B2B 生产力工具设计，
设计语言对标 Linear / Vercel / Raycast / Stripe：克制的暗色、精确的间距节奏、清晰的信息层级、克制的动效。

# MISSION
对「Goal Compiler · 诉求拆解平台」（商务科技深色）进行整体视觉与信息架构优化，
重点：输入区两大功能（模板库 / AI 多轮澄清）的排布，与「图片中的排列方式」对齐——
做到「突出但不拥挤」：核心操作一眼可见、次要能力随手可达、面板之间呼吸感充足。

# DESIGN PRINCIPLES
1. 层级三阶：标题/正文/辅助（h2 16-18 / 正文 14 / hint 12），权重靠字号与颜色而非堆砌装饰。
2. 间距节奏：区块 16-20px、组内 8-12px、相关元素间距 < 无关元素间距（就近原则）。
3. 拥挤治理：一行只放一个主行动；可横向滚动而非纵向堆叠；折叠默认收起次要面板。
4. 深色科技：底 #070b14，面板 #0f172a 渐变，主色蓝→青渐变 #3b82f6→#22d3ee，正文 #e6edf7，次级 #94a3b8。
5. 可读性：正文对比度 ≥ 7:1，焦点可见（辉光），空/载/错三态齐备。
6. 动效克制：fade ≤ 0.2s、hover 位移 ≤ 1px、无弹跳无夸张。

# CONCRETE EXECUTION LIST
- [x] 输入区重排：模板库改为「单行横向滚动条」（不占纵向空间）；AI 澄清改为「可折叠卡片」默认收起，展开后呼吸感充足
- [x] 推荐模板内联到输入区下方，轻量展示 Top3
- [x] 竞品分析双视图：本产品视图增加「关联数据源」与「同口径扫描」，与需求分析流程一致
- [x] GitHub 限流治理：Token 输入（可选）+ 状态徽标（未认证/已启用）
- [x] 间距节奏精修：容器/卡片/按钮/标签统一 4px 基准的倍数；响应式断点优化
- [x] 层次强化：面板标题、分区头、空状态文案统一风格

# ACCEPTANCE
- 打开 http://localhost:8910/#/compile：输入区一眼可辨「主输入 + 模板横条 + AI 澄清卡片」，无拥挤感
- 竞品 Tab 两个视图结构一致、数据源可见、GitHub 状态清晰
- E2E ≥ 53 项全绿；单测 ≥ 21 项全绿
```

## 二、v8 执行结果

| 项 | 优化前 | 优化后 |
|----|--------|--------|
| 模板库 | 双列常驻卡片（占纵向空间） | **单行横向滚动条**，标签 + 可滚动 chip，零拥挤 |
| AI 多轮澄清 | 常驻展开聊天（挤压输入区） | **可折叠卡片**，默认收起，展开后有足够空间 |
| 推荐模板 | 埋在模板库内 | 输入下方轻量 Top3 内联 |
| 本产品分析 | 无数据源信息 | **关联数据源徽标（9 源）** + 同口径扫描按钮与结果 |
| GitHub 限流 | 提示"稍候" | **Token 可选配置**（5000/时）+ 状态徽标 + 限流友好提示 |
| 全局精修 | 间距/层级基础 | 统一 4px 间距基准、焦点辉光、卡片/按钮/标签一致性、响应式优化 |
