## 5. 风险与应对（项目管理视角）

| 风险 | 等级 | 应对 |
|------|------|------|
| 无 LLM 后端，规则引擎深度有限 | 中 | 文档明示定位；P2 规划 LLM 增强模式 |
| GitHub API 未认证限流（10 次/分） | 中 | 精选库离线兜底 + 前端提示 |
