# 05 · 商业价值分析

## 1. 市场背景

- AI Agent（Claude Code / Codex / Cursor）用户快速增长，**「给 Agent 下对目标」成为高频刚需**；
- 现有方案分散：Skill 类（文本）、SaaS 类（重平台）、编译类（无思维链/无编辑/无情报）；
- **「可视化思维链 + 可编辑目标资产 + 产品总监级竞品情报」三者合一的产品目前缺位**。

## 2. 市场规模（估算）

| 口径 | 估算 |
|------|------|
| Claude Code + Codex + Cursor 活跃开发者 | 千万级（2026 增长期） |
| 其中「需频繁拆解复杂目标」的 Agent 重度用户 | 数百万级 |
| 目标客单价（SaaS 订阅 / 团队版） | $9-29 / 月 |
| 可服务市场（SAM）年化 | 千万美元级 |

## 3. 商业模式

| 模式 | 说明 | 阶段 |
|------|------|------|
| 免费开源（当前） | 本地运行、零依赖、数据私有 | ✅ 获客 |
| 进阶订阅 | LLM 深度生成、团队空间、Skill 导出 | P2 |
| 企业版 | 团队流程标准化 + 私有化部署 | P2 |
| 生态变现 | Skill 市场分发、与 Agent 工具链集成分成 | P3 |

## 4. 单位经济模型（假设）

- CAC：内容获客 + 开源口碑 ≈ $0-3/用户
- LTV：订阅 $15/月 × 留存 18 个月 ≈ $270
- LTV/CAC ≈ 90（开源驱动下极健康）
- 毛利：SaaS 订阅 >80%（LLM API 成本占比 <15%）

## 5. 竞争优势（护城河）

1. **思维链可学习性**：竞品只给结论，本产品把「怎么拆」结构化展示——这是内容壁垒；
2. **目标资产沉淀**：可编辑 + 历史 + 导出，用户数据越用越有价值（切换成本）；
3. **产品总监级情报**：内置竞品分析，帮用户做「要不要做」的决策；
4. **零依赖本地化**：隐私友好，企业可私有化。

## 6. 风险

| 风险 | 应对 |
|------|------|
| 官方（Anthropic/OpenAI）内置 Goal 编译 | 差异化在「教 + 沉淀 + 情报」，而非「生成」本身 |
| SaaS 巨头补齐拆解能力 | 绑定 Agent 生态 + 开源社区先行 |
| 规则引擎深度有限 | P2 接入 LLM 增强，规则引擎作为「确定性基底」 |

## 7. Go / No-Go 建议（产品总监结论）

**建议 GO**：
- 成本极低（零依赖本地 MVP 已跑通，10/10 E2E）；
- 差异化清晰（思维链 + 编辑 + 情报三件套）；
- 先以开源 + 社区内容（「如何写 Goal」教程）获客，验证「教学型工具」需求后，再上订阅。

**关键验证指标（下一步）**：
1. GitHub Star / 下载量（获客）；
2. 「思维链」页停留时长与导出率（学习价值）；
3. 付费意愿测试：$9/月「LLM 深度版」转化率。
