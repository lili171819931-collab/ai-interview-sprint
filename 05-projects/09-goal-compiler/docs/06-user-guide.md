# 06 · 使用指南

## 1. 快速开始

```bash
cd 05-projects/09-goal-compiler
node server/server.mjs 8910
# 浏览器打开 http://localhost:8910
```

> 零依赖：Node ≥ 18 即可，无需 npm install。

## 2. 界面总览（5 个 Tab）

| Tab | 功能 |
|-----|------|
| 诉求拆解 | 输入模糊想法 → 编译 → ①-⑨ 结构化结果 + 可编辑 Goal |
| 思维链 | 14 个推理节点逐步展开，可导出 MD/JSON |
| 竞品分析 | 多源爬取 + 产品总监视角分析（定位矩阵/SWOT/建议） |
| 案例库 | 3 个测试用例，一键载入编译 |
| 关于 | 项目说明与文档索引 |

## 3. 典型操作流程

1. **输入诉求**：粘贴一段「模糊想法」（一句话或一段描述均可）；
2. **可选**：展开「可选补充信息」，填写目标用户/时间盒/约束，提升精度；
3. 点击 **⚡ 开始编译**；
4. 阅读 ①-⑧ 结构化分析（关键假设、目标树、边界、验收、风险）；
5. 查看 **＋ 你没考虑到的方向**（基于领域自动补全）；
6. 在 **⑨ 最终 Goal Prompt** 中直接编辑、复制、下载；
7. 点 **存草稿** → **历史** 可随时恢复；
8. 切到「思维链」逐步学习编译过程，可导出；
9. 切到「竞品分析」输入关键词检索，得到产品总监级报告。

## 4. 竞品分析使用

- 默认开启 GitHub / Hacker News / 精选库 三源；
- GitHub 未认证限流 10 次/分：连续检索请间隔或只勾选「精选库」；
- 表格点击表头排序；定位矩阵按「产品化 × 拆解深度」四象限；
- 「导出分析报告 MD」可沉淀到项目文档。

## 5. 测试用例（3 个）

| 用例 | 诉求类型 | 演示重点 |
|------|----------|----------|
| AI 面试官工具 | 产品/构建 | 目标树、边界、验收标准 |
| 报销发票小程序 | 效率/自动化 | 自动补全（合规/识别率/异常处理） |
| AI 英语口语提升 | 学习/成长 | 个人目标的里程碑与自测关卡 |

## 6. 常见问题

- **GitHub 检索报限流？** 稍候重试，或只勾选「精选库」离线分析。
- **想生成更复杂的目标？** 补充「目标用户/时间盒/约束」信息后再编译。
- **数据存在哪里？** 全部本地（localStorage + 本地文件），不经过任何服务器。
