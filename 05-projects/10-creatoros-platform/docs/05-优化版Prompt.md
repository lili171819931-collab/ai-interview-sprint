# CreatorOS · AI 自媒体全平台增长操作系统（增强版 V2）

## 〇、执行总纲

你现在是一支由顶级产品负责人、AI Agent 架构师、自媒体增长专家、全栈工程师、数据分析师、
商业化专家组成的「AI 自媒体产品研发公司」。

你的唯一目标：**独立完成一个可长期使用、可演进为商业 SaaS 的「AI 自媒体全平台增长操作系统」Web App**，
并且：

1. 不堆功能，只做能回答「5 个问题」的闭环；
2. AI 是核心能力不是装饰；
3. 所有模块数据打通；
4. 全程诚实：真实 / 快照 / Mock / 未接入 四态可见，禁止假装成功；
5. 【新增】输出「完整思维链结构化文档」，让任何人能快速掌握搭建本产品的完整思维链条；
6. 【新增】内置「竞品情报雷达」：从 GitHub、Awesome 列表、AI 导航站、Product Hunt、行业网站等
   多平台爬取当前现有类似 Skill/产品，执行竞品分析与对比，并从产品总监视角输出战略报告；
7. 【新增】按项目制交付：产品分析 → 全项目流程管理 → 开发测试 → 商业价值分析 → 完成报告，并打包上传 GitHub。

## 一、产品定位与核心公式

- 产品名：CreatorOS
- 定位：AI 自媒体全平台增长操作系统
- 心智公式：`数据 → 洞察 → 选题 → 创作 → 发布 → 复盘 → 反哺`
- 一句话价值：**让一个人拥有一支完整的 AI 自媒体团队。**

## 二、信息架构（收敛为 7+3 导航）

1. 指挥中心 Dashboard（5 问一屏）
2. 热点雷达（Hot Topic Engine + Hot Score）
3. 对标研究（账号情报 / 暴力拆解 / 对标矩阵）
4. 选题中心（AI Topic Factory + Topic Score）
5. AI 内容工厂（文案 / 变体 / 脚本 / 分镜 / 素材）
6. 发布与数据（内容日历 / 发布中心 / 数据中心 / AI 复盘）
7. 增长系统（AI 增长顾问 / Agent 团队 / 工作流 / 知识库 / 设置）
- 【新增】A. 思维链中心：完整思维链结构化输出（学习型差异化）
- 【新增】B. 竞品情报雷达：多平台 Skill/产品爬取 + 对比 + 产品总监报告
- 【新增】C. 项目文档中心：产品分析 / 项目管理 / 开发测试 / 商业价值 / 完成报告

## 三、核心功能要求（保留原始 + 增强）

### 3.1 热点雷达
- 统一 Hot Topic Engine；接入源：搜索趋势 / 新闻 / 社交 / 视频 / RSS / 自定义 / 第三方 API
- Hot Score 综合评分 + 频段徽章（🔥爆发中 / 📈快速增长 / ⚠️高竞争 / 💰商业价值高）
- 热点详情：热度曲线 / 传播路径 / 关键词 / 代表内容 / 头部账号参与 / AI 内容机会（7 切入角度）/
  自动生成 20 个可执行选题
- 【新增】热点来源可信度标注与去重（同一事件跨平台合并，避免一鱼多吃）

### 3.2 对标研究与暴力拆解
- 账号情报库：头部 / 腰部 / 新锐 / 增长最快 / 爆款 / 潜力
- 一键暴力拆解：人设 / 定位 / 内容结构 / 爆款选题 / 标题公式 / 视频结构 / 爆款公式
- 对标矩阵：我的账号 VS 多个竞品，10 维对比 + 「该学什么不该学什么」

### 3.3 选题中心
- AI Topic Factory：输入方向/热点/账号/赛道 → 10/30/100 个选题
- Topic Score 7 维评分（热点性/用户需求/传播性/差异化/竞争/商业价值/制作难度）→ 推荐制作

### 3.4 AI 内容工厂
- 文案生成器（主题/目标用户/平台/风格/字数/目标 → 标题+正文+Hook+CTA+标签）
- 文案变体引擎（专业/犀利/故事/情绪/反常识/干货/爆款/IP 版 + 一键改写）
- 视频脚本工厂（标题/定位/Hook/分镜/口播/字幕/B-roll/音乐/转场/CTA）
- 【新增】平台原生适配矩阵：一个核心内容 → 抖音/小红书/视频号/B站/快手/微博/知乎/公众号 原生改写
  （标题/长度/标签/封面比例/CTA/表达风格随平台变化）

### 3.5 发布与数据
- 发布中心：草稿/审核/待发布/发布中/已发布/失败；立即/定时/批量/智能排期
- 数据真实性：无平台 API 时发布一律 Mock 标注，绝不假装成功
- 数据中心：播放/阅读/点赞/评论/收藏/分享/涨粉/转化 × 平台/账号/内容/赛道/时间
- 爆款分析 + 内容复盘（Post-Mortem）+ AI 增长顾问（可访问全系统数据回答问题）

### 3.6 AI Agent 团队与工作流
- 9 位 Agent：热点侦察 / 竞品情报 / 选题专家 / 文案专家 / 导演 / 视频制作 / 发布运营 / 数据分析 / 增长负责人
- 协作流水线：热点 → 研究 → 选题 → 文案 → 导演 → 视频 → 发布 → 数据 → 增长 → 反哺
- Workflow Builder：Trigger → Research → Analyze → Generate → Review → Publish → Analyze
- 【新增】工作流可观测：每次运行记录输入/输出/成本/状态，支持重跑与回滚

## 四、【新增】数据真实性 & 合规体系（本次重点补充）

1. 四态可见：真实数据 / 快照数据 / Mock 数据 / API 未接入，全链路 UI 标注；
2. 内容合规审核：生成内容预检（广告法极限词、平台敏感词、版权风险、低俗/医疗/金融等强监管类目）；
3. 平台政策风险提示：数字人标识、营销内容报备、限流规则变化预警；
4. 用户数据安全：数据加密、导出、删除权（个保法/GDPR 兼容设计）、账号多因素认证预留；
5. AI 内容可追溯：每条生成记录留存 Prompt/模型/版本/成本，支持审计。

## 五、【新增】商业化与付费体系（本次重点补充）

1. 定价：Free / Pro / Team / Business / Enterprise；
2. 计费维度：账号数 / AI 额度 / 视频生成额度 / 存储 / 席位 / 工作流数；
3. 额度计量组件（用量仪表盘 + 阈值告警）从第一天埋点；
4. AI 成本控制：Model Router + 缓存 + 批量 + 重试 + Fallback + Token/成本统计；
5. 【新增】付费墙 A/B 与留存指标：免费→Pro 转化率、次日/7 日留存、每日简报打开率。

## 六、【新增】技术架构增强（本次重点补充）

1. 分层：UI → 视图逻辑 → 领域引擎 → 数据 → Provider Adapter；
2. 外部能力全 Adapter：LLMProvider / VideoProvider / ImageProvider / VoiceProvider /
   PublishProvider / DataProvider / HotTopicProvider；
3. 【新增】可观测性：日志、指标、错误追踪、灰度发布、A/B 实验接口预留；
4. 【新增】Skill/Plugin 生态兼容：预留 MCP / Claude Skill 接入层，吸纳社区单点能力；
5. 【新增】多端：Web 优先，预留移动端 H5 与浏览器插件（一键采集竞品/热点）；
6. 数据模型：Workspace 隔离 + 对象血缘（Topic.sourceTopicId 等），支撑归因与复盘。

## 七、【新增】完整思维链输出（学习型差异化功能）

1. 目的：让用户/开发者快速掌握「如何从 0 搭建一个 AI 增长 OS」的完整思维链条；
2. 形式：按阶段结构化输出（需求理解 → 产品定位 → 信息架构 → 数据模型 → 技术架构 →
   商业化设计 → 开发策略 → 测试验证 → 增长运营）；
3. 每个节点包含：问题 → 思考过程（多步推理）→ 备选方案 → 决策 → 产物 → 复盘要点；
4. 支持：阶段筛选、节点展开、自动播放、导出 JSON/Markdown；
5. 【新增】「决策日志」机制：未来每次产品决策自动追加为思维链节点，让系统自己长出方法论。

## 八、【新增】竞品情报雷达（独立功能模块）

1. 数据源：GitHub Search / Awesome 列表 / Toolify / Product Hunt / 新榜等行业网站 / 公众号与
   知识星球 Skill 市场；
2. 爬取管线：发现 → 抓取 → 清洗 → 结构化 → 入库 → 分析；无网时使用快照并标注；
3. 分析输出：
   - 特性覆盖率与对比矩阵；
   - 市场空白带（差距分析）；
   - 定位象限（平台广度 × AI 深度）；
   - 产品总监视角战略报告（市场洞察 / 定位建议 / 差异化杠点 / 进入策略 / SWOT / 风险对冲）；
4. 更新机制：定时重跑 + 新源接入向导。

## 九、【新增】项目制交付要求

1. 交付物：产品分析文档、全项目流程管理（WBS/里程碑/风险登记册）、开发与测试文档、
   商业价值分析、产品完成报告、可运行 Web App、3 个以上可运行测试用例；
2. 每个模块遵循：开发 → 运行 → 测试 → 发现问题 → 修复 → 再次运行；
3. 最终把项目完整打包并推送到指定 GitHub 仓库目录（05-projects/）。

## 十、最终验收

用户进入系统 → 建立账号 → 选择赛道 → 发现热点 → 查看竞品 → 暴力拆解账号 →
生成选题 → 生成文案 → 生成脚本 → 内容工作台 → 生成内容 → 安排发布 → 查看数据 →
AI 复盘 → 得到下一轮建议 —— 全链路闭环且数据打通。

## 十一、最重要的一句话

> **不要做一个「功能很多」的自媒体工具；要做一个能不断学习用户、学习竞品、学习热点、
> 学习内容数据，并且越来越懂「什么内容值得做、怎么做更容易成功」的 AI 内容增长操作系统。**
