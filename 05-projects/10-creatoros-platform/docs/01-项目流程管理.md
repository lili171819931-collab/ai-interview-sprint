## 1. 项目目标

在 `05-projects/10-creatoros-platform/` 下交付一个可运行的 Web 端「AI 自媒体全平台增长操作系统」，
包含：完整产品分析、全项目流程管理、开发测试、商业价值分析、完整思维链输出、竞品情报爬取分析、3 个测试用例，
并推送至 GitHub。

## 4. 风险登记册

| 风险 | 影响 | 概率 | 应对 |
|------|------|------|------|
| 无网络/无 API | 无法实时抓取 | 高 | Mock+快照+Adapter，诚实标注；crawl-skills.mjs 留真实入口 |
| 平台 API 政策不稳 | 发布/数据能力受限 | 中 | Provider Adapter 抽象，发布层不假装成功 |
| AI 成本不可控 | 商业模型受损 | 中 | Model Router + 缓存 + Token 统计 |
| 大厂自带工具增强 | 单点功能被替代 | 高 | 押注数据闭环与思维链差异化 |
| 竞品快速跟进 | 差异化窗口缩短 | 中 | 私有数据壁垒 + 每日价值推送留存 |
