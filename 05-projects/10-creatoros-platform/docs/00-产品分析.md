# 00 · 产品分析（CreatorOS）

> AI 自媒体全平台增长操作系统 · 项目制文档 1/5
> 版本 v1.0 · 2026-08-14

---

## 1. 需求理解

原始诉求：构建一个可长期使用的「AI 自媒体全平台增长操作系统」Web App，
完成从「发现机会 → 内容生产 → 发布 → 增长复盘」的完整闭环，并逐步演进为商业化 SaaS。

### 1.1 用户 5 问（产品成立性检验）

| 问题 | 系统如何回答 | 对应模块 |
|------|--------------|----------|
| 今天什么值得做？ | 今日机会榜 + AI 建议 | 指挥中心 / 热点雷达 |
| 我的竞争对手最近在做什么？ | 竞品动态 + 暴力拆解 | 对标研究 / 竞品情报 |
| 我应该做什么内容？ | 今日推荐选题 + Topic Score | 选题中心 |
| 内容怎么快速做出来？ | 文案/脚本一键生成 | AI 内容工厂 |
| 发布以后效果怎么样？ | 数据卡 + 趋势图 + AI 复盘 | 数据中心 / 增长分析 |

### 1.2 核心公式与飞轮

```text
热点 → 趋势判断 → 赛道分析 → 头部账号 → 竞品研究 → 爆款拆解
  → 选题生成 → 内容策略 → 文案 → 脚本 → 视觉 → 素材 → 制作
  → 审核 → 多平台适配 → 发布 → 数据监控 → 复盘 → 反哺下一轮
```

数据飞轮：`数据 → 洞察 → 选题 → 创作 → 发布 → 数据 → 复盘 → 策略优化 → 下一轮内容`

## 2. 用户画像与场景

| 画像 | 特征 | 痛点 | 付费意愿 |
|------|------|------|----------|
| 个人创作者 | 1-3 账号，日更/周更 | 不知道做什么、产出慢、看不到效果 | 中高 |
| 一人公司 | 全栈内容+产品+销售 | 时间稀缺、需要系统化增长 | 高 |
| 小团队 | 3-10 人内容团队 | 协作、统一品牌、批量生产 | 高（团队版） |

冷启动目标用户：**个人创作者 / 一人公司**（决策快、痛点痛、付费真实）。

## 3. 竞品分析摘要（详见「竞品情报」视图与 03-商业价值分析）

| 类型 | 代表 | 强项 | 缺失 |
|------|------|------|------|
| 数据平台 | 新榜/蝉妈妈/飞瓜/新红 | 榜单与数据 | 无 AI 生产、无闭环 |
| 生产工具 | 剪映/稿定/智影 | 单点执行 | 无决策与数据回流 |
| AI 写作 | Jasper/Copy.ai/Notion AI | 通用生成 | 中文多平台适配弱 |
| Skill 生态 | Claude/ChatGPT Skills | 迭代快、低成本 | 碎片化、无数据闭环 |

**市场空白**：热点→创作→发布→复盘全链路闭环 + 多平台原生化 + 可解释思维链输出。

## 4. 产品定位

> **CreatorOS · AI 自媒体全平台增长操作系统 —— 让一个人拥有一支完整的 AI 自媒体团队。**

- 心智公式：`数据 → 洞察 → 选题 → 创作 → 发布 → 复盘 → 反哺`
- 差异化：不做「功能很多的自媒体工具」，做「越来越懂你的内容增长 OS」。
- 壁垒：内容数据 + 账号数据 + 竞品数据 + 用户知识库 + 历史表现 + Agent/Workflow + 增长反馈
  → 最终形成 **Creator Intelligence Graph**。

## 5. 信息架构（收敛后的导航模型）

原始需求 22 个一级模块，按价值链归类收敛为 **7 个业务导航 + 3 个能力导航**：

```text
01 指挥中心（Dashboard）
02 热点雷达（热点/趋势/评分）
03 对标研究（账号中心/爆款拆解/对标矩阵）
04 选题中心（选题工厂/评分）
05 AI 内容工厂（文案/脚本/分镜/素材）
06 发布与数据（日历/发布/数据中心/复盘）
07 增长系统（AI 顾问/Agent 团队/工作流/知识库/设置）
────────────────────────────
A 思维链（完整思维链结构化输出 · 学习型差异化）
B 竞品情报（多平台 Skill/产品爬取分析 · 产品总监视角）
C 项目文档（产品分析/项目管理/开发测试/商业价值/完成报告）
```

收敛原则：`操作路径短`、`信息密度高`、`闭环优先`。

## 6. 核心用户流程（首次体验）

```text
创建账号 → 选择赛道 → 绑定平台 → 建立个人 IP → 导入竞品
  → AI 分析 → 生成内容战略 → 生成 30 天选题 → 生成内容
  → 排期 → 发布 → 数据 → AI 复盘 → 下一轮建议
```

新用户体验爆点：**10 分钟内从「什么都没有」变成「拥有完整内容增长计划」**（Creator Growth Blueprint）。

## 7. 数据模型（核心实体）

围绕「人-内容-反馈」四层建模，MVP 收敛为 18 张核心表：

| 层 | 实体 |
|----|------|
| 用户/工作区 | User · Workspace · Membership(Role) · Subscription/Quota |
| 内容主体 | Creator · Brand · Platform · Account |
| 内容资产 | Topic(sourceTopicId) · Content · ContentVersion · Script · Scene · Asset · Template |
| 分发/反馈 | Campaign · Schedule · Publication · Metric · Analytics · PostMortem |
| AI 能力 | Agent · Workflow · WorkflowRun · Knowledge · Prompt · AIJob |

关键关系（打通闭环）：

```text
Topic.sourceTopicId → Trend/HotTopic     （选题来自热点）
Content.topicId      → Topic              （内容来自选题）
Publication.accountId+platformId          （发布到哪个账号哪个平台）
Metric.contentId     → Content            （数据挂到内容）
PostMortem.contentId → Content            （复盘挂到内容）
WorkflowRun          → Workflow+AIJob     （工作流与 AI 调用可追踪）
```

## 9. 验收标准（最终闭环）

```text
用户进入系统 → 建立账号 → 选择赛道 → 发现热点 → 查看竞品
  → 暴力拆解账号 → 生成选题 → 生成文案 → 生成脚本
  → 进入内容工作台 → 生成内容 → 安排发布 → 查看数据
  → AI 复盘 → 得到下一轮建议
```

数据真实性原则：`真实数据 / 快照数据 / Mock 数据 / API 未接入` 四态全链路可见，禁止假装成功。
