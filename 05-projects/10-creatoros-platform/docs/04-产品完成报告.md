## 4. 技术债

- 原生 JS 单文件视图较大，后续按模块拆分为 TypeScript 组件；
- 无后端：多用户与持久化依赖 localStorage，商业版需迁移 PostgreSQL；
- 思维链数据为静态 JSON，未来可由「决策日志」自动生成；
- 无自动化 UI 测试，仅核心引擎有单测。

## 5. 下一阶段建议（P1）

1. 接入 LLMProvider（OpenAI/Claude）验证生成质量与成本；
2. 实现素材库 + 模板系统；
3. Agent 编排流水线（热点→选题→文案→脚本 全自动）；
4. Workflow Builder 拖拽编辑；
5. 知识库 + 个人 IP 大脑（让 AI 越来越像用户自己）。

## 6. 真实 API 接入点清单

| 能力 | 推荐接入 |
|------|----------|
| 热点 | 微博热搜/知乎热榜/百度指数/B站热门/Google Trends |

| AI | OpenAI / Claude / Gemini（Model Router） |

| 竞品 | GitHub Search API / Toolify / Product Hunt API |
| 数据仓库 | PostgreSQL + Redis + S3（对象存储） |

## 7. 商业化建议

1. 先验证「10 分钟出增长计划」的首日价值留存；
2. Pro 定价 ¥69/月，免费版跑通闭环做口碑；
3. 用「案例库 + 每日简报」做产品即营销；
4. 押注数据壁垒（Creator Intelligence Graph）而非单点功能；
5. 与平台方工具（剪映/智影）建立 Provider 合作而非对抗。
