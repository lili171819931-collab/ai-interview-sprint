# 02 · 开发与测试（CreatorOS）

---

## 1. 技术选型与理由

| 决策 | 选择 | 理由 |
|------|------|------|
| 形态 | 纯前端工程化 SPA（原生 JS 模块化） | 零依赖、可运行、可测试、可演进；不依赖构建网络 |
| 样式 | 自研设计系统 styles.css | 商务高效简约，参考 Linear/Notion/Stripe 的信息密度 |
| 领域逻辑 | src/lib/*.js（UMD 纯函数） | 浏览器与 Node 测试共用，逻辑可单测 |
| 数据 | src/data/*.js 种子 + data/*.json 快照 | 诚实标注 Demo/快照/Mock |
| 外部能力 | Provider Adapter（LLM/Video/Publish） | 未来无痛接入真实服务 |
| 服务 | scripts/serve.mjs（node 零依赖） | 一键本地运行 |

演进路径：`原生 SPA → Next.js + TypeScript + PostgreSQL + Queue → 商业 SaaS`。

## 3. 核心引擎说明

### 3.1 热点评分（src/lib/scoring.js）

```text
Hot Score = Σ(信号×权重) − 竞争×0.7 − 生命周期风险×0.6
信号权重：热度20% 增长20% 讨论10% 传播10% 关注10% 相关性10% 商业10%
频段：≥85 爆发中 / ≥70 快速增长 / ≥55 值得追踪 / ≥40 建议观察
徽章：⚠️高竞争(竞争≥75) 💰商业价值高(商业≥80) 🚀增速极快(增长≥80) ⏳长生命周期
```

### 3.2 选题评分（src/lib/scoring.js）

```text
Topic Score = 7 维加权（竞争与制作难度取反向）
≥85 S 级 / ≥80 A 级推荐制作 / ≥70 B 级 / 其余 C 级
```

### 3.3 竞品分析（src/lib/competitor.js）

```text
覆盖率 = 已支持特性 / 全部特性
差距分析 = 各特性支持者数量排序 → 空白带
定位象限 = x 平台广度 × y AI 深度 → 四象限分类
产品总监报告 = 洞察 + 战略（定位/差异化/进入/风险）+ SWOT
```

### 3.4 爬虫管线（src/lib/crawler.js）

```text
发现源 → 抓取 → 清洗 → 结构化 → 入库 → 分析
来源适配器：GitHub Search / Awesome 列表 / Toolify / Product Hunt / 行业网站
状态：snapshot（快照已收录）/ mock / todo（未接入）
```
