# 指标与评测：微迹 AI 周复盘

## 北向指标（业务）

1. **周复盘打开率**：有资格用户中打开复盘的比例  
2. **次周打卡完成率**：看过复盘人群 vs 对照（分层：本周打卡天数）  
3. **7 日留存**：试点期相对基线的变化  
4. **有害反馈率**：标记「不准/冒犯/乱催」的占比（越低越好）

## 南向指标（系统）

1. **数字一致率**：抽检生成文案中的数字与 Fact Card 一致的比例（目标 ≥99%）  
2. **校验通过率**：生成后通过校验器的比例  
3. **降级率**：最终只展示 Fact 的比例（监控异常飙升）  
4. **P95 延迟**：点击到出文案 &lt; 8s  
5. **单用户周成本**：生成次数 × 单价，设预算上限

## 黄金集计划（面试务必能讲）

- **首批样本**：40–60 条  
  - 稳定完成周、断签周、单习惯、满 7 习惯、数据不足、刚重启 streak 等
- **覆盖难例**：
  - 模型想夸大完成率
  - 模型建议「明天补打昨天」
  - 模型输出羞辱/鸡汤过度
  - 模型编造不存在的习惯名
- **标注**：产品主标；抽 20% 交叉标
- **更新**：每周把「反馈不准」进入集

## 上线闸门（全部满足才全量）

- [ ] 黄金集数字一致率 ≥ 99%
- [ ] 违禁（代打卡/补打/医疗诊断/羞辱）漏放 = 0（抽检）
- [ ] 数据不足路径 100% 走规则降级
- [ ] P95 延迟达标或稳定降级
- [ ] 隐私文案与关闭开关可用
- [ ] 成本看板与周配额生效
