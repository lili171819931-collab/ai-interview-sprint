# 辅作品：最小 RAG 验证（可选但加分）

## 目标

用最小成本证明你理解 RAG，不只是会写 PRD。

## 两条路径（二选一）

### 路径 A：会一点代码
- 用任意框架搭一个本地/在线问答（文档 ≤ 20 篇）
- 记录：切分策略、检索效果、失败案例、改进

### 路径 B：不会代码（同样成立）
- 用产品方式完成「人工模拟 RAG」：
  1. 准备 10 个问题 + 对应应召回文档
  2. 标注检索是否正确
  3. 写生成约束与拒答规则
  4. 输出评测表与结论

## 交付

- [ ] `hypothesis.md`：要验证的假设
- [ ] `eval-sheet.md`：10 条评测
- [ ] `lessons.md`：3 条教训（可进面试）

## 面试怎么讲

「我不是为了做 demo 而做 demo，而是为了验证：没有知识治理和评测，RAG 体验上不去。」
