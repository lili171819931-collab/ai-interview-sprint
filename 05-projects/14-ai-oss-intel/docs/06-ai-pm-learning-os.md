# AI PM Learning & Content Intelligence OS（最高优先级战略补充）

> 平台真正定位：**AI Product Manager Growth OS**
> 一句话：Study Great AI Products. Think Like a PM. Build Your Career.

GitHub 项目只是数据源；真正的核心是训练产品判断能力，
最终形成四层资产：知识资产（Cases）→ 能力资产（Product Thinking）→ 内容资产（Social Content）→ 职业资产（Portfolio + Resume + Interview）。

## 已实现模块

### 1. AI PM 学习模式（项目页 `#pm-learning`）
- **Socratic Product Learning**：先让用户思考，再给 Expert Review
- 难度分级：Beginner / Intermediate / Advanced / Expert（每级 4 题 × 72 项目）
- **Hidden Needs Detector**：表层 / 功能 / 深层 / 潜在需求
- **需求树**：从 Feature 追到 Job（Why 链）
- **JTBD**：When / I want / So that + Functional / Emotional / Social Job
- **用户需求证据**：Evidence / Inference / Hypothesis 三级区分
- **AI Native 分析**：AI Before / After / Native
- **PM 视角 vs 普通用户视角**

### 2. 产品拆解模式（`#deconstruct`）
- **Project DNA 底层逻辑图**（11 节点：用户→痛点→需求→场景→产品→功能→AI 能力→Workflow→结果→价值→商业模式）
- **AI 产品五层拆解模型**（User Problem / Product Experience / AI Capability / Agent Workflow / Business Model）

### 3. 自媒体模式（`#content`）
- 一键生成 **8 平台内容**：小红书 / 公众号 / Bilibili / YouTube / X / LinkedIn / 抖音 / 视频号
- **观点注入**：项目事实 + AI 分析 + 我的观点 = 最终内容（避免洗稿）
- **一键视频脚本**：Hook → Problem → Product → Why → Breakdown → AI Logic → Business → My PM Opinion → CTA
- **Content Score**：Hook / Information / Originality / Product Insight / Practical Value / Shareability
- 发布后沉淀到 Content Portfolio

### 4. 求职 Portfolio 模式（`#portfolio`）
- **Portfolio Case**：Problem / User / Product Logic / AI Architecture / Business Model / My Decision / Improvement
- **Interview Me**：AI 面试官（Product Director / AI Product Lead / Hiring Manager）即时评分
- **AI PM 面试题库**：8 类 × 72 项目（Product Sense / User Research / AI Product / Metrics / Growth / Business / Technical / Strategy）
- **Rebuild This Product**：自动生成 Product Brief / PRD / User Flow / Feature List / MVP / AI Architecture / Data / Metrics / GTM
- **If I Were The PM**：用户先写判断，再与 AI PM 对比
- **Product Decision Journal**：我的决策 + 理由 + AI 意见 + 最终判断

### 5. AI PM 学习中心（`/learn`）
- **My AI PM Journey**：Day 计数 + 7 类学习统计
- **能力雷达图**：10 维能力（Product Thinking / AI Understanding / User Research / Requirement Analysis / Feature Design / AI Agent / Business Model / Growth / Data Analysis / Communication）
- **AI PM Score** + **能力缺口 → 项目推荐**
- **30 Days AI PM Challenge**：Week 01 理解产品 → Week 02 理解 AI → Week 03 产品设计 → Week 04 商业
- **每日任务**：分析 1 个项目 / 找 3 痛点 / 找 5 功能 / 判断为什么需要 AI / 找商业化机会 / 写 PM 判断
- **学习而不是收藏**：项目级完成度（Overview→Challenge 9 步），收藏 ≠ 学习完成

### 6. 面试模式（`/interview`）与作品集（`/portfolio`）
- 面试模式：选项目逐题练习 + 全题库浏览
- Portfolio：About Me（可编辑）+ Cases + 决策日志 + 观点 + 内容 + 导出 JSON

## 能力评估逻辑
学习状态存储在 localStorage（`aioss.learn.*`），能力分由真实行为推导：
- 完成项目拆解步骤 → 对应能力加分
- 答对 Challenge / 完成面试 / 写决策 / 写观点 → 能力加分
- 能力缺口推荐对应排行榜项目补齐

## 30 天成功标准
连续使用 30 天 → 60-90 个 Cases / 20+ Agent Cases / 20+ SaaS Cases / 30+ 观点 / 20+ 内容 / 10+ Portfolio Cases / 100+ 面试题，
面试时能自然回答「最近研究过哪些 AI 产品 / 你最喜欢哪个 Agent / 它的核心产品逻辑 / 如果重新设计你会怎么做」。
