# PRD · GitHub AI 开源情报与产品分析平台

## 1. 产品定位
把 GitHub 从「代码仓库」转化为「AI 开源项目雷达」，帮助用户发现 → 理解 → 判断 → 学习 → 复刻 → 二次开发 → 商业化，形成完整闭环。

**品牌**：AI Open Source Intelligence Platform
**副标题**：Discover. Analyze. Build. Monetize.

## 2. 核心用户
| 用户 | 关注点 |
|------|--------|
| AI 产品经理 | 趋势、Agent、Skills、MCP、AI SaaS、产品机会 |
| AI 开发者 | 技术架构、Agent、LLM、RAG、MCP、Coding Agent |
| Vibe Coding 用户 | 可直接复刻/二次开发/快速 Demo 的项目 |
| 副业创业者 | 能赚钱、能 SaaS 化、能做成服务/模板/Skill 的项目 |
| 自媒体创作者 | AI 热点、爆款项目、内容选题 |
| 求职者 | 简历项目、AI Portfolio、面试案例 |

## 3. 核心场景
1. **每日发现**：今天哪些 AI 开源项目值得关注？
2. **增长情报**：最近 30 天 Star 增长最快的项目？
3. **副业判断**：哪个项目适合一个人做副业 / SaaS？
4. **简历提升**：哪个项目二开最能写进简历？
5. **机会生成**：这个开源项目能衍生出什么新产品？

## 4. MVP Scope（V1）
- ✅ GitHub API 数据采集（可选实时）
- ✅ 项目抓取与分类（30 大类多标签）
- ✅ Star Top 50 / Growth Top 50
- ✅ 项目详情页 + AI 分析报告（25 节）
- ✅ AI Project Score 评分体系
- ✅ 项目对比 Compare
- ✅ AI Chat（自然语言查询平台数据）

## 5. 成功标准
输入：「找出最近 30 天增长最快、适合个人开发者、可以做副业、最好能 SaaS 化的 AI 项目。」
系统自动完成 搜索→筛选→排序→评分→深度分析→商业分析→竞争分析→推荐，
输出 Top 3 并回答：为什么 / 复制什么 / 不复制什么 / 增加什么 / 目标用户 / MVP / 技术 / 收费 / 获客 / 周期 / 风险。

## 6. UI/UX 原则
- 3 秒知道项目是什么
- 10 秒知道为什么重要
- 30 秒知道是否值得关注
- 3 分钟知道是否值得复制
- 10 分钟知道是否值得商业化
- 30 分钟可以开始建立自己的产品

## 7. 非目标（V1）
- 不做真实用户账号体系（Watchlist 用 localStorage）
- 不做实时流式 Agent 对话（用本地确定性分析引擎）
- 不接付费 LLM API（AI Provider 抽象已预留）
