# LLM 产品能力包

## 你要掌握的不是调参，而是决策

对每个 AI 功能，面试官真正想听的是：

1. **为什么用 AI**（相对规则/搜索/人工的增量）
2. **边界在哪**（什么不做、什么转人工）
3. **怎么知道好不好**（指标与评测）
4. **坏了怎么办**（兜底、回滚、审计）
5. **值不值得**（成本、延迟、组织成本）
