# 何时用 AI / 何时不用

## 决策框架（面试可直接用）

满足越多越适合 AI：
1. 任务有自然语言/非结构化输入
2. 规则难以穷举，但错误可容忍或可复核
3. 有可获取的知识/工具/反馈闭环
4. 人力重复度高，自动化 ROI 明确
5. 延迟与成本可接受

出现以下信号则谨慎或不用：
1. 必须 100% 正确（资金、医疗关键决策、法律生效动作）
2. 无数据/无反馈，无法迭代
3. 规则已足够稳且便宜
4. 无法设计人审或兜底
5. 组织没有运营评测的人
