# 评测与上线闸门

## 核心观点

不会评测的 AI 产品经理 = 不会验收的产品经理。

## 最小评测体系

1. **黄金集**：50–200 条真实难例（持续维护）
2. **分层指标**：
   - 正确性 / 有用性
   - 引用可靠性
   - 安全违规率
   - 延迟与成本
3. **评估方式**：规则 + 模型判分 + 人工抽检
4. **线上闭环**：点踩、转人工、会话标注回流

## 上线检查清单（可直接带去面试）

- [ ] 场景边界写清楚（不做清单）
- [ ] 有拒答与转人工策略
- [ ] 有权限与审计
- [ ] 离线评测过关（定义阈值）
- [ ] 有灰度与回滚
- [ ] 有成本看板
- [ ] 有坏案例值班机制
- [ ] 成功指标与业务指标对齐

## 面试句式

「我上线 AI 功能时，不先看模型分数，先看三件事：任务完成率、不可接受错误率、单位成本。模型指标服务于这三件事。」
