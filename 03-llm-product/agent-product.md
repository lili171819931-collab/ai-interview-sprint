# Agent 产品设计（面试版）

## 一句话

Agent = 模型不止回答，还能规划并调用工具完成任务；核心不是「更聪明」，而是「可控地行动」。

## 做 / 不做决策树

```
任务是否需要多步 + 外部系统？
 ├─ 否 → 用普通 LLM/RAG
 └─ 是 → 错误成本是否高？
      ├─ 高 → 必须人机回环 / 分步确认
      └─ 低 → 可自动执行，但要审计与限额
```

## 产品必须设计的 6 件事

1. 目标：用户要完成什么任务
2. 工具清单：能调什么、不能调什么
3. 权限：身份、数据范围、操作级别
4. 停机条件：何时结束、何时升级人工
5. 可观测：每步做了什么，可否回放
6. 成本护栏：最大步数、最大金额、最大时长

## 面试高频对比

| | Chatbot | RAG | Agent |
|--|---------|-----|-------|
| 核心 | 对话 | 有据回答 | 行动完成任务 |
| 风险 | 胡说 | 检索错 | 做错事 |
| 产品重点 | 体验 | 知识治理 | 权限与流程 |
