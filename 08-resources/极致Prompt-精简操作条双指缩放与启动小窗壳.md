════════════════════════════════════
M2. 触屏双指共触 → 网页放大
════════════════════════════════════
目标：在触控板/触屏场景下，两指同时接触并做捏合（pinch）时，对「教学强调缩放层」或预览/成片中的网页区域进行放大，便于讲网页细节。

Must：
1. 识别双指捏合手势（优先：触控板 pinch / gesture 事件；Electron 渲染进程 wheel+ctrl 常映射捏合，亦可监听 gesturestart/gesturechange 若可用）。
2. 行为：
   - 双指张开 → 放大（倍率上限建议 3x）
   - 双指捏合 → 缩小（下限 1x）
   - 以双指中点（或当前指针/焦点）为缩放中心
   - 缩放效果进入合成层，预览 = 成片（与现有 pointer-zoom / lens 体系整合或替换为「手势驱动的网页放大」）
3. 与鼠标指针缩放的关系：
   - 双指捏合是本轮主路径；鼠标悬停放大可保留为次路径或合并为同一 magnification 状态。
   - 禁止两套缩放互相打架；统一一个 zoom 状态机。
4. 无触控设备降级：
   - ⌥+滚轮 或 ⌘+滚轮 等效捏合；写进 README。
5. 复位：双击操作条「复位」或快捷键恢复 1x（若删除缩放按钮，必须提供复位手段）。

硬约束：
- 缩放只影响屏幕内容层，不影响摄像头小窗人像清晰度。
- 关闭/复位后无残影。
- macOS 上不要依赖仅移动端才有的 touch 事件而不做触控板降级。

验收：

4. 录一段含捏合放大的 MP4，回放可见放大过程。

M3. 鼠标单击小窗 → 切换窗口形状

Must：
1. 在合成预览画布上：单击命中小窗区域（非拖动）→ 切换 circle ↔ rect。
2. 区分单击与拖动：
   - pointerdown → move 超过阈值（如 6px）视为拖动，松手吸附，不切换形态；
   - pointerdown → pointerup 位移小于阈值且时间较短 → 视为单击，切换形态。
3. 切换后预览与成片立即同步；中心锚点尽量保持。
4. 操作条与主设置中不再提供「圆形」快捷按钮（见 M1）；主界面可用文案提示「单击小窗切换圆/方」。
5. 录制中单击仍可切换（若性能不足，至少预览可切并文档说明）。

验收：
6. 单击小窗：圆→方→圆，成片形态一致。
7. 拖动小窗改位置时不会误触发形态切换。
8. 操作条无形态按钮后，仍能完成形态切换。
