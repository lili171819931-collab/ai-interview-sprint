# 极致 Prompt：实时录屏 + 圆形摄像头小窗 + 收音 App（仅 macOS）

> 可整段复制给 Cursor / Claude / GPT。  
> 目标：从 0 到 1 做出可演示的「屏幕录制 + 圆形摄像头画中画 + 麦克风」个人录制工具。  
> **平台锁定：只做 macOS**（Apple Silicon + Intel）。不做 Windows、不做 iOS/Android。

---

```text
你是「个人录制工作室」的产品负责人 + 音视频工程师 + macOS 桌面客户端工程师。
任务：搭建一款 **仅面向 macOS** 的软件 App：实时录屏 + 圆形小窗口摄像头个人出镜 + 收录麦克风声音；交付可演示、可导出的本地 MVP。

【平台锁定（不可扩展范围）】
- 唯一目标平台：macOS（同时支持 Apple Silicon 与 Intel）。
- 明确不做：Windows、Linux、iOS、Android、Web 在线版、跨端同步。
- 文档、代码、依赖、打包脚本全部按 macOS-only 设计；禁止为「将来移植」预留半成品抽象层导致延期。
- 打包产物：.dmg 或可直接运行的 macOS app（dev + 本地 package）。

【产品一句话】
在 Mac 上一键开始 → 同时录屏幕 + 圆形摄像头小窗 + 麦克风 → 实时预览合成画面 → 停止即得到一条可分享的本地视频。

【核心用户场景】
1. 教程/讲解：录全屏或指定窗口，右下角圆形人脸出镜，同步讲解声。
2. 演示/路演：录指定应用窗口 + 人声讲解。
3. 多屏办公：在外接显示器与内建屏之间切换录制源，小窗位置可拖。
用户痛点：macOS 自带截屏/录屏没有可合成进成片的圆形摄像头小窗；用剪辑软件后期叠加太重。

【硬约束】
1. 隐私优先：默认本地录制、本地预览、本地导出；未经用户明确授权，不上云、不上传、不埋点可识别内容。
2. 权限透明：首次使用必须清晰申请并解释：屏幕录制、摄像头、麦克风；并给出 macOS「系统设置 → 隐私与安全性」跳转/路径说明。拒绝任一权限时给出可恢复引导，不白屏、不静默失败。
3. 合成进成片：最终导出的视频必须已合成「屏幕画面 + 圆形摄像头叠加 + 音频」；禁止只录两路再让用户去 Final Cut / 剪映里拼。
4. 实时预览：录制过程中预览区必须看到摄像头圆形小窗叠加在屏幕画面上的最终构图（所见即所得）。
5. 性能底线：1080p@30fps 连续录制 ≥ 20 分钟不崩溃；CPU/内存异常时降级（降分辨率/帧率）并提示，不丢整段成片。
6. 失败可恢复：权限被拒、设备占用、磁盘不足、编码器失败，都要有明确中文错误文案 + 下一步动作。
7. 不做：云剪辑社区、美颜滤镜大全、多人协作、账号体系、Windows/手机端（全部砍掉）。

【技术栈（必须先冻结，写进决策记录）】
二选一，选定后不要来回换：
- 方案 1（默认建议）：Electron + desktopCapturer / getDisplayMedia + getUserMedia + Canvas 合成 + MediaRecorder（或 FFmpeg 导出）
- 方案 2：Tauri 2 + macOS 屏幕采集 + 本地编码（更轻，集成成本更高）
默认选 Electron 以最快出可演示 MVP。若选 Tauri，须在 Step 0 说明理由。

【macOS 权限与系统注意点（必须落地）】
- 屏幕录制：Screen Recording 权限；未授权时引导打开系统设置对应页。
- 摄像头：Camera 权限。
- 麦克风：Microphone 权限。
- Info / entitlements / 权限文案齐全，避免打包后无法授权。
- 菜单栏或 Dock 需有明显「正在录制」态，禁止隐蔽录制。
- 系统声音（loopback）：MVP 不做强依赖。若做可选开关，须明确依赖 BlackHole/虚拟声卡或等价方案，并在 UI 标注「需额外安装」；默认只保证麦克风。

【MVP 功能清单（Must）】
A. 录制控制
- 开始 / 暂停 / 继续 / 停止
- 倒计时 3 秒（可关）
- 录制中：菜单栏图标或悬浮控制条（时长、暂停、停止、麦克风静音）
- 快捷键：开始/停止、静音、显示/隐藏摄像头小窗（可配置；注意与系统快捷键冲突检测）

B. 屏幕源
- 选择：整个屏幕 / 指定窗口 /（可选）指定区域
- 实时预览选中的源
- 多显示器时列出全部显示器（含外接屏）

C. 圆形摄像头小窗（关键体验）
- 开启/关闭摄像头叠加
- 强制圆形裁切（不要方窗+圆角假装；遮罩必须是正圆）
- 可拖拽位置；可缩放大小（例如直径 120–360px）
- 可吸附四角；默认右下角，边距可配置
- 可选：圆形描边、轻微阴影（克制，不要花哨贴纸风）
- 水平镜像默认开（符合自拍习惯）
- 摄像头设备切换（ Continuity Camera / 外接摄像头若系统可见则可选）
- 录制中可隐藏小窗（画面不再叠加），但不要悄悄丢权限

D. 声音
- 麦克风开关 + 输入设备选择 + 实时电平表
- 系统声音：非 Must；若做则标注 macOS 限制与安装指引
- 静音时成片无爆音、无直流噪声突变

E. 输出与成片
- 默认格式：MP4（H.264 + AAC）；可用 QuickTime Player 直接打开验收
- 分辨率：跟随屏幕源或限制到 1080p/720p（Retina 下注意逻辑分辨率 vs 物理像素，预览与导出一致）
- 帧率：30fps 默认；可选 24/60（60 视性能降级）
- 导出目录可选；停止后「在 Finder 中显示」
- 文件命名：YYYYMMDD-HHMMSS-screen-cam.mp4
- 可选 sidecar JSON（时长、分辨率、是否含摄像头、是否含麦）

F. 设置页
- 默认摄像头/麦克风/导出目录/快捷键/是否倒计时/小窗默认大小与位置/镜像开关
- 关于与隐私说明（本地录制声明）
- 「打开系统隐私设置」快捷入口

【交互与视觉（克制、专业工具感）】
- 不是营销落地页；是录制工作台。
- 主界面三段：左侧源选择 + 中间实时合成预览 + 右侧设备/小窗/音频控制。
- 预览区必须是「最终成片构图」：屏幕为底，圆形摄像头叠在上层。
- 避免：紫白渐变、过量玻璃拟态、圆角胶囊堆叠、emoji 装饰。
- 用清晰层级、高对比控制按钮、录制中红色脉冲计时。
- 圆形小窗拖拽要跟手；松手可吸附。
- 符合 macOS 桌面习惯：标准窗口控件、原生感菜单、Finder 集成。

【技术实现要点（必须写进方案，禁止空谈）】
1. 采集
- 屏幕：Electron desktopCapturer 或 getDisplayMedia；处理用户取消授权。
- 摄像头：getUserMedia({ video: true })；小窗约束较低分辨率即可。
- 麦克风：getUserMedia({ audio: true })；处理设备热插拔。

2. 实时合成（二选一，推荐先 A）
- A. Canvas/WebGL：每帧 drawImage(屏幕) → 圆形 clip 后 drawImage(摄像头) → canvas.captureStream → 与音频轨汇合 → MediaRecorder
- B. 分轨临时文件 + 停止后 FFmpeg 圆形 overlay（预览仍必须实时合成）
- 选定后在 README 写清利弊。

3. 圆形遮罩
- clipPath circle / destination-in；输出像素级圆形，边缘抗锯齿。
- 小窗坐标相对成片画布计算，导出与预览一致（Retina 缩放尤其不能漂）。

4. 音视频同步
- 统一时间线起步；长时间录制开发态可打漂移日志。

5. 存储与性能
- timeslice 分片或流式写入，避免整段进内存。
- 磁盘低于阈值（如 2GB）禁止开始并提示。
- 录制中降低无关动画。

6. 权限文案（中文）
- 屏幕：「用于录制你选择的屏幕或窗口画面，仅存本机。」
- 摄像头：「用于圆形出镜小窗，仅在你开启时采集。」
- 麦克风：「用于录制讲解声音，可随时静音。」

【信息架构 / 窗口】
- 主窗口工作台：源 + 预览 + 控制
- 设置
- 首次权限引导
- 导出完成对话框（在 Finder 中显示、再录一条）
- 帮助：快捷键 + 系统设置路径（屏幕录制/摄像头/麦克风）

【数据与文件契约】
- 成片：{exportDir}/{timestamp}-screen-cam.mp4
- 可选 sidecar：同名 .json
  {
    "createdAt": "ISO-8601",
    "platform": "macos",
    "durationMs": 0,
    "width": 1920,
    "height": 1080,
    "fps": 30,
    "camera": { "enabled": true, "mirrored": true, "diameterPx": 200, "x": 0, "y": 0 },
    "audio": { "mic": true, "system": false },
    "sourceType": "screen|window|region",
    "appVersion": "0.1.0"
  }
- 用户设置：本地 JSON/electron-store；不进 git。

【非目标（写进 README，防止膨胀）】
- Windows / Linux / iOS / Android 任何移植工作
- 云端存储与分享社区
- 自动字幕/AI 脚本/数字人
- 完整时间线剪辑器
- 美颜磨皮贴纸商场
- 强依赖系统声录制（可作为可选实验，非验收阻塞）
- 游戏级 144fps 抗花屏优化
- 未授权的隐藏录制能力

【验收标准（必须在 macOS 实测）】
1. 选择全屏 → 开圆形摄像头 → 开麦 → 录 30 秒 → 停止 → 得到 MP4；用 QuickTime Player 打开：
   - 能看到屏幕内容
   - 能看到圆形（非方形）摄像头叠加
   - 能听到人声
2. 录制中拖动小窗到左上角，成片位置与预览一致（含 Retina）。
3. 关闭摄像头小窗再录，成片无摄像头、有屏幕与人声。
4. 静音麦克风再录，成片无有效人声。
5. 拒绝摄像头权限：文案清晰，可恢复；行为符合设定（仅录屏+麦或阻断）。
6. 拒绝屏幕录制权限：无法开始，引导至系统设置。
7. 连续录制 10 分钟：可正常停止并打开成片；无崩溃。
8. 多显示器下可切换屏幕源。
9. Apple Silicon 与 Intel 至少验证其一为必过；另一架构若无法实测，在验收表标注「未测」。
10. README 含：安装、权限路径、开始录制、导出、已知 macOS 限制。

【执行顺序】
Step 0：输出作战计划（1 页内）：确认 macOS-only、技术栈、合成方案、MVP 边界、权限风险。

Step 5：补齐暂停/快捷键/设置/权限引导/菜单栏录制态。

Step 8：可选 backlog 仅限 macOS 内（如 BlackHole 系统音、区域录制精修）；禁止把 Windows/手机写入下一步 Must。

【开始指令】
```
