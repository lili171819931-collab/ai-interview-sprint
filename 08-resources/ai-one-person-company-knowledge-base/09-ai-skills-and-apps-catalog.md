# AI Skill 与 App 分类导航

> 目标：把“可复用技能/工作流”和“可直接使用或复刻的 AI App”放在同一张地图里。  
> 使用方式：先按场景选 Skill，再选 App 或 GitHub 项目复刻。  
> 说明：商业产品链接用于体验和找灵感；GitHub 链接用于学习架构和快速改造。

| 项目 | 一页纸总结 |
|---|---|
| 文件定位 | AI Skill、App、商业产品和 GitHub 项目的分类导航。 |
| 适合对象 | 需要按能力选择工具的人，例如编程、Agent 搭建、RAG、自动化、爬取、多模态、语音、数据分析、客服 CRM。 |
| 核心内容 | 每类 Skill 对应的 App 官网、GitHub 项目、适合能力、可复刻方向和一人公司组合建议。 |
| 立即行动 | 先选一个 Skill 组合：AI SaaS、知识库、Agent、自动化服务或多模态内容工具。 |
| 关键产出 | Skill 组合地图、App 链接、GitHub 链接、可复刻产品方向。 |

## 11. 一人公司 Skill 组合建议

### 组合 A：最快做 AI SaaS

- Skill：AI Chat + 登录 + 数据库存储 + 支付 + 埋点。
- App/GitHub：Vercel AI Chatbot、Supabase、Stripe Samples、PostHog、shadcn/ui。
- 适合产品：面试助手、内容助手、文档分析助手。

### 组合 B：最快做知识库产品

- Skill：文档解析 + Embedding + RAG + 引用 + Eval。
- App/GitHub：RAGFlow、LlamaIndex、Unstructured、Qdrant、Ragas。
- 适合产品：企业 SOP、合同问答、课程陪练。

### 组合 C：最快做 Agent 产品

- Skill：任务拆解 + 工具调用 + 浏览器 + 人工确认 + 报告。
- App/GitHub：LangGraph、Browser Use、Firecrawl、GPT Researcher、n8n。
- 适合产品：竞品监控、市场研究、销售线索。

### 组合 D：最快做 AI 自动化服务

- Skill：表单接入 + AI 分类 + 邮件 + CRM + 人工审核。
- App/GitHub：n8n、Activepieces、Chatwoot、Twenty CRM、OpenAI Cookbook。
- 适合产品：AI 自动化代运营、客服质检、销售跟进。

### 组合 E：最快做多模态内容工具

- Skill：图像生成 + 文案生成 + 批量模板 + 导出。
- App/GitHub：ComfyUI、Fooocus、InvokeAI、Vercel AI SDK、shadcn/ui。
- 适合产品：电商图、社媒图、课程封面、营销素材。
