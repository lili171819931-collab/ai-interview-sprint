## 一句话结论

当前 AI 模型生态已从「通用全能」转向分层格局：

**通用打底 → 专项极致 → 底座支撑 → 智能执行 → 行业落地**

选型核心原则：

1. 不滥用顶配模型  
2. 不用通用模型硬替代专项模型  
3. 商用场景优先合规与可验证效果  
4. 最终以真实业务样本测试为准

## 1. 五大核心分类（PDF 框架）

本 PDF 按技术架构 / 核心能力 / 落地场景划分为五类，强调减少分类重叠。可与本仓库的「十类能力分层」对照使用，见下方映射表。

### 1.1 通用基础大模型

- 定位：自然语言理解、逻辑推理、多轮交互的文本底座。
- 擅长：文案、公文、逻辑拆解、科普、润色、摘要、翻译、方案策划、复杂问题推理。
- 优势：门槛低、通用性强、迭代快，多数非专业需求可直接落地。
- 短板：垂直专业精度不足；原生视觉/影音生成弱；超高精度代码、超长文档精读、工业级专业分析有瓶颈。
- 场景：日常问答、职场文案、学习答疑、通用方案、普通文本处理。
- 代表（2026 口径，需核验）：GPT-4o、Claude 4 系列、Gemini 2.5 Pro、DeepSeek-V4、智谱 GLM、通义千问、文心一言、豆包大模型。
- 属性：以商用闭源为主，部分提供轻量开源版与免费额度。

### 1.2 专项能力模型

基于通用模型针对单一能力极致优化，含 5 个子类。

#### 超长上下文文档专项

- 擅长：十万字级精读、多文件对比、合同/财报/书籍审查、长文本纠错、论文拆解、批量资料整合。
- 优势：超大上下文窗口，长文本细节留存更高。
- 短板：创意生成弱，联网与多模态体验一般。
- 场景：法务、财报、学术、书籍精读、企业批量文档。
- 代表：Claude Opus 系列、Kimi Pro、Gemini 超长文本版、讯飞星火超长文档模型。

#### 代码开发专项

- 擅长：多语言代码生成、工程调试、漏洞修复、重构、迁移、算法落地、脚手架、注释生成。
- 短板：通用文案与创意弱。
- 场景：开发、调试、项目搭建、自动化脚本。
- 代表：DeepSeek-Coder、通义灵码、GitHub Copilot、Cursor 代码模型、腾讯相关代码产品。

#### 全维度多模态专项

- 擅长：图文解析、截图解题、图片识别、视频语义、音频转写、跨模态创作、场景分析。
- 短板：专业绘画、影视级视频生成不如垂直影音模型。
- 场景：图文答疑、课件解析、多媒体办公。
- 代表：GPT-4o、Gemini 2.5、豆包多模态、讯飞星火多模态。

#### AI 图像生成专项

- 擅长：绘画、电商主图、海报、IP、高清修复、风格迁移、背景精修。
- 短板：无逻辑推理与复杂文本分析能力。
- 场景：设计、电商美工、新媒体视觉、艺术创作。
- 代表：Midjourney、Stable Diffusion、DALL·E、通义万相、文心一格、即梦 AI。

#### AI 音视频生成专项

- 擅长：文生视频、剪辑、补帧、配音、音乐、降噪、字幕、数字人、微短剧。
- 短板：文本逻辑分析与专业办公决策不足。
- 场景：短视频、微短剧、影视剪辑、企业宣传片。
- 代表：Sora、Runway、Pika、MiniMax、剪映 AI、讯飞智音。

### 1.3 技术底座模型

- 定位：无直接对话创作能力，为 RAG、检索、推荐提供底层支撑。
- 擅长：向量化、相似度匹配、知识库检索、聚类去重、模糊搜索、推荐、问答库搭建。
- 短板：不能独立完成创意生成、复杂推理与用户交互。
- 场景：企业 RAG、智能客服、海量分类检索、个性化推荐。
- 代表：OpenAI Embedding、百川 Embedding、通义 Embedding、智谱 Embedding、DeepSeek Embedding。

### 1.4 AI 智能 Agent 模型

- 定位：自主规划、工具调用、多步骤拆解、闭环执行、自我纠错。
- 擅长：复杂任务拆解、全网调研、批量办公自动化、多工具联动、竞品复盘、长期任务迭代。
- 短板：简单单次任务性价比低；复杂任务仍有偏差，需人工校验。
- 场景：企业自动化、市场调研、批量数据处理、智能工作托管、开发自动化。
- 代表：GPT Agent 方向产品、Gemini Agent、豆包智能体、Dify、Coze、腾讯 WorkBuddy、字节 TRAE IDE。

### 1.5 行业垂直专用模型

- 定位：行业专属数据微调，强调合规与业务逻辑。
- 擅长：法律文书、医疗问诊筛查、金融分析、教育题库、工业质检、文创、财税、政务、营销。
- 短板：通用性差，跨领域效果下降。
- 场景：法律、医疗、金融、教育、工业、文创、政务、营销等专业落地。
- 代表：各行业商用定制模型（法律 / 医疗 / 金融 / 文创 / 营销 / 人社等）。

## 4. 场景选型对照表

| 核心场景 | 优先模型类型 | 备选方向 | 使用建议 | 避坑提示 |
|---|---|---|---|---|
| 通用文案、办公写作、日常问答 | 通用基础大模型 | 通义 / DeepSeek 等国产通用模型 | 轻量需求用国产；复杂逻辑用顶配通用模型 | 勿用专项模型做通用写作 |
| 十万字长文档、合同、财报精读 | 超长上下文专项 | Gemini / 讯飞超长版 | 批量多文件优先长文本专长模型 | 通用模型易遗漏细节 |
| 代码开发、调试、工程重构 | 代码专项 | 通义灵码 / Copilot | 工程级优先专项代码模型 | 通用模型隐性漏洞风险更高 |
| 图文解析、截图解题、多媒体办公 | 多模态专项 | 豆包多模态 | 复合多媒体优先顶配多模态 | 单一绘画/视频别硬用多模态 |
| 专业绘画、海报、电商视觉 | 图像生成专项 | 通义万相 / 文心一格 | 高精度商用可看海外；日常可用国产 | 勿用纯文本模型做视觉 |
| 短视频、微短剧、数字人 | 音视频生成专项 | 剪映 AI / Runway | 专业影视与自媒体成片路径分开 | 通用文本模型无法稳定出片 |
| 企业知识库、RAG、智能检索 | Embedding 底座 | 国产向量模型 | 私有化优先国产向量模型 | 勿用生成模型替代向量模型 |
| 自动化办公、批量调研、自主执行 | Agent | Coze / WorkBuddy 等 | 多步骤复杂任务再用智能体 | 长周期任务需人工收尾校验 |
| 法律 / 医疗 / 金融等专业作业 | 行业垂直模型 | 通用顶配 + 人工审核 | 商用专业场景优先垂直模型 | 通用输出不可直接商用 |

## 5. 全文选型逻辑（摘要）

- 个人日常办公、轻量化创作：通用大模型  
- 单一高精度场景：对应专项模型  
- 企业技术底座：向量 / Embedding  
- 复杂自动化：Agent  
- 行业商用落地：垂直专属模型 + 合规与人工审核
