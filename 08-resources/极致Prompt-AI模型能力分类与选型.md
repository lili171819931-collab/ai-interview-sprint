# 极致 Prompt：AI 模型能力分类与选型

> 可整段复制给 Cursor / Claude / GPT / Gemini / Perplexity / Deep Research 类工具。  
> 目标：生成一份面向产品经理的 AI 模型分类、能力边界、查询渠道、选型框架和可信度报告。  
> 配套研究文档：[`ai-model-capability-taxonomy-and-selection.md`](./ai-model-capability-taxonomy-and-selection.md)

---

```text
你是一名资深 AI 产品研究员、技术架构顾问、模型评测专家和 AI 产业分析师。

请基于 2025-2026 年最新市场情况，系统研究“市面上的 AI 工具与模型类型分类”。目标读者是一名产品经理，需要快速理解 AI 模型生态、能力边界、适用场景、查询渠道，并能据此完成 AI 工具或模型选型。

请严格按“模型能力”分类，而不是只按厂商或品牌分类。

请特别区分三件事：
1. 模型能力分类：模型本身能做什么。
2. AI 工具分类：产品把模型包装成什么工作流。
3. 应用场景分类：业务里用它解决什么问题。

一、请先建立 AI 模型能力分类体系

至少覆盖以下类型：
1. 通用大语言模型 LLM
2. 推理模型
3. 代码模型
4. 多模态模型
5. 图像生成/编辑模型
6. 视频生成模型
7. 语音模型
8. Embedding/检索模型
9. Agent/工具调用模型
10. 垂直领域模型

每一类请说明：
- 定义
- 核心能力
- 擅长任务
- 不适合任务
- 典型产品场景
- 代表模型/产品
- 主要厂商
- 常见定价方式
- 推荐查询网站
- 可信度判断

二、请从产品经理视角分析使用场景

请覆盖：
- 内容生产
- 市场营销
- 客服/销售
- 知识库/RAG
- 数据分析
- 编程/研发效率
- 设计/创意素材
- 教育培训
- 企业流程自动化
- 多模态交互
- 个人效率工具

每个场景请说明：
- 最适合的模型类型
- 推荐工具或模型方向
- 成功指标
- 主要风险
- 是否适合从 MVP 开始验证

三、请给出查询和验证渠道

请按以下类别列出可查询的网站，并说明每类网站适合查什么：
- 官方文档与 API 价格
- 模型排行榜
- Benchmark 评测
- 开源模型社区
- API 聚合平台
- AI 工具目录
- 用户评论与产品社区
- 行业报告与研究机构

必须包含但不限于：
OpenAI、Anthropic、Google AI、Google DeepMind、Meta AI、Mistral、DeepSeek、阿里云百炼、腾讯混元、百度千帆、智谱 AI、Hugging Face、ModelScope、OpenRouter、Together AI、Replicate、硅基流动、Artificial Analysis、LMArena / Chatbot Arena、Stanford HELM、Papers with Code、SWE-bench、MMMU、MMLU、GPQA、VBench、Futurepedia、There’s An AI For That、Product Hunt、G2。

四、请建立 AI 模型选型评分框架

请从以下维度打分或分析：
- 成本
- 响应速度
- 准确性
- 推理能力
- 中文能力
- 代码能力
- 多模态能力
- 上下文长度
- 工具调用能力
- API 稳定性
- 数据安全
- 私有化部署能力
- 生态成熟度
- 学习成本
- 商业可持续性

请给出 1-5 分评分标准，并说明不同业务场景下如何调整权重。

五、请输出决策建议

请分别给出以下场景的推荐选型思路：
1. 创业公司做 AI 产品
2. 企业内部知识库/智能助手
3. 个人效率工具
4. 内容营销团队
5. 研发团队
6. 教育或培训产品
7. 客服/销售自动化产品

每个场景请输出：
- 推荐模型组合
- 不推荐的选择
- MVP 验证方式
- 成本与风险提示
- 可信度评级

六、请做来源交叉验证

请把结论分成三档：
- 高可信：来自官方文档、官方价格页、正式 changelog、可复现 Benchmark、企业 SLA、真实业务 A/B 数据。
- 中可信：来自第三方榜单、工具目录、用户评论、行业媒体、社区复现、API 聚合平台。
- 低可信：来自社交媒体爆料、未经验证的排行榜截图、厂商营销话术、单个 Demo、无来源转载。

请对关键结论标注可信度，并说明判断依据。
如果信息来源冲突，请明确指出冲突点，不要直接下绝对结论。

七、输出格式要求

请使用结构化中文输出，避免空泛描述。
不要只罗列品牌，要解释不同模型类型背后的能力差异。
涉及价格、排行榜、模型版本时，请注明“需以官网最新信息为准”。
请尽量用产品经理能理解的语言表达，但保持专业深度。

最后请输出：
1. 一份“AI 模型能力分类地图”
2. 一份“AI 模型选型速查清单”
3. 一份“不同业务场景推荐模型类型”
4. 一份“推荐查询网站清单”
5. 一套“产品经理选择 AI 工具的决策流程”
6. 一份“可信度与风险说明”
```

## 使用建议

### 快速版

如果只想得到一份概览报告，可以补充：

```text
请控制在 3000 字以内，优先输出分类、代表产品、适用场景和查询网站。
```

### 深度版

如果要做竞品研究或项目立项，可以补充：

```text
请输出适合落地到产品文档的版本，并给出 MVP 验证计划、数据指标、风险清单和 30 天调研路线图。
```

### 资源沉淀版

如果要沉淀到资源库，可以补充：

```text
请把结果整理为可长期复用的知识库文档，字段包括：modelType、capability、representativeProducts、bestUseCases、risks、sourceUrls、confidence、updatedAt、pmInsight。
```

## 信心说明

- Prompt 完整度：高。已覆盖模型能力、工具分类、业务场景、来源渠道、选型框架和可信度。
- 信息实时性：中。Prompt 要求模型查询 2025-2026 年信息，但具体结果仍取决于执行模型是否具备联网能力。
- 选型可落地性：中高。适合做初筛和 PM 研究，最终仍需用真实业务样本测试。
- 风险控制：中高。已要求标注来源、冲突信息和可信度，但不应替代法律、医疗、金融等专业判断。
