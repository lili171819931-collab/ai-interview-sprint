# GTM Co-Founder 本地安装与打开

来源：[AIDevGTM/gtm-cofounder](https://github.com/AIDevGTM/gtm-cofounder)

## 已完成

1. 仓库克隆到：`08-resources/gtm-cofounder/`
2. Skills 安装到 Cursor 个人目录：`~/.cursor/skills/`（含 `00-start-here` … `17-review-the-work`）
3. 同步用 `npx skills add AIDevGTM/gtm-cofounder` 装到该仓库的 `.agents/skills/`

说明：这不是独立桌面 App，而是 **Cursor / Claude 的 Agent Skills 包**。打开方式是读 `AGENTS.md`，从 `00-start-here` 开始访谈。

## 如何打开使用

在 Cursor 对话里粘贴：

> You are my GTM co-founder. Read `08-resources/gtm-cofounder/AGENTS.md` and the skills. Start with `00-start-here` to interview me one question at a time and write `docs/gtm-cofounder/founder-brief.md`. Then run `01-strategy-and-roadmap` to produce `docs/gtm-cofounder/gtm-roadmap.md`.

入口文件：

- `08-resources/gtm-cofounder/AGENTS.md`
- `08-resources/gtm-cofounder/skills/00-start-here/SKILL.md`
- `08-resources/gtm-cofounder/README.md`
