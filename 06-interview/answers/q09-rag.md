# Q09：用大白话讲 RAG 全流程

## 60–90 秒答案

1. **定义**：先从企业知识里找回相关证据，再让模型基于证据回答。  
2. **为什么重要**：把「背诵世界知识」变成「查阅你们的知识」，降低胡编、提高可追溯。  
3. **例子**：员工问「差旅报销标准」，系统检索制度文档后回答并给出条款引用。  
4. **权衡/坑**：文档乱、切分差、检索不准时，RAG 会「一本正经地错」。  
5. **产品动作**：知识治理 → 检索质量 → 生成约束 → 引用展示 → 评测与回流。

## 流程口述（可背）

问题改写 → 检索 → 重排 → 带证据生成 → 展示引用 → 点踩反馈 → 坏案例进入黄金集
